# ultramax400_r01：整卷翻拍曝光条件与整卷片基（S2-5）

数据：37 张 NEF（Nikon Z 7_2，Bayer，无片边）。脚本：`scripts/roll_exposure.py` → `frames.json`，
`scripts/roll_base.py` → `roll_base.json`。只走分析路径（CFA 感知），不做反马赛克。

## 1. 翻拍曝光条件（EXIF 核实）

| 项目 | 37 张中的取值 | 对片基估计的影响 |
|---|---|---|
| ISO | 100（全部） | 相同，帧间抵消 |
| 光圈 | f/16（全部） | 相同，帧间抵消；电子光圈每次收缩的重复精度未验证，属中性误差 |
| 镜头、焦距 | NIKKOR Z MC 105mm f/2.8 VR S，105 mm（全部） | 相同 |
| 白平衡（as-shot 系数） | 全部相同 | 引擎不使用 |
| 曝光模式 | 光圈优先、矩阵测光、+1 EV、电子前帘快门 | 快门由相机按每格内容测出 |
| 快门 | 1/25～1/60（14 张 1/30，11 张 1/50，8 张 1/40，3 张 1/25，1 张 1/60） | **需要归一化** |
| 拍摄时间 | 2024-03-30 20:33:39～20:34:41，共 62 秒 | 光源漂移的时间窗口很短 |
| 信号水平 | 扣黑电平后最大值只到满量程的 11%～23% | 翻拍曝光偏低约 2～3 档；没有饱和像素 |

快门归一化：信号 ∝ 透射率 × 曝光时间，所以按 `rgb × t_ref / t` 换算到 t_ref = 1/30。
EXIF 标称值（如 1/30）和它通常代表的精确 1/3 档值（2^-5 = 1/32）最多相差 6.7%（约 0.028 D）。
真实快门时间没法从文件验证。两种取法都算了：整卷片基只差 ≤ 0.007 D。

**关键性质：** 快门、光圈、ISO、光源强度的误差都是**中性的**（三个通道同比例变化），只影响片基的亮度，
不影响通道之间的比例，因此不会造成偏色。造成偏色的是通道比例的误差，它来自光源光谱的变化或者场景密度
（把带颜色的暗部当成片基）。

## 2. 光源稳定性

翻拍画面里没有不被底片遮挡的区域，也没有片边，所以**光源强度没法直接测**。间接证据：

- **光谱稳定（有证据）：** 最低密度簇（见下）由 11 帧组成，从第一帧 3823（20:33）到 3858（20:34），色度 log2(R/G)、log2(B/G)
  的极差只有 0.07 和 0.04，没有随时间漂移。
- **强度稳定（无法单独验证）：** 簇内帧之间的亮度差（G 通道 0.086 D）混合了三样东西，场景（不是每格都碰到底）、
  快门舍入（≤ 0.028 D）和光源强度变化，现有数据分不开。三者都是中性误差。

以后自采数据时，平场帧（不放底片只拍背光）和固定快门可以消除这一项不确定性，已列入采集协议待办。

## 3. 3822 不是片基

3822 是这卷第一帧，画面几乎是均匀的橙色，之前被当作片基候选。实测结论相反：

- 相机给它的快门最长（1/25），说明它很**密**，不是很薄。
- 归一化后，它最透明的区域比整卷的“底”还密 **0.47 D**（G），在 37 帧里最密。
- 色度偏橙：log2(R/G) = +0.555，簇中心是 +0.005。

合理的解释是装片时卷首漏光、雾化（未验证）。清单里已经标为假设。

## 4. 整卷片基

方法（`filmcolor.base.estimate_base_roll`，纯函数）：每帧先用 `estimate_base_auto` 找画面内部最透明、
均匀、色度一致的区域，再按快门归一化，然后找“最低密度簇”。簇的条件是 G 通道密度在最透明那帧的 0.1 D 以内，
并且色度落在簇中心 ±0.05（log2）以内。片基取簇里最透明 3 帧的逐通道中位数。

依据：场景暗部到了胶片趾部以下，色度会收敛到片基加灰雾的颜色；没碰到底的帧，最亮处仍带着场景颜色（偏橙）。

| 结果 | 值 |
|---|---|
| 簇成员 | 11 帧：3847, 3823, 3853, 3844, 3843, 3849, 3856, 3845, 3857, 3858, 3824 |
| 采用 | 3847, 3823, 3853 |
| 片基（t = 1/30，线性，1 = 白电平） | R 0.1859，G 0.1893，B 0.0762 |
| 簇中心色度 log2(R/G), log2(B/G) | +0.005，−1.313 |
| 是否有区域比候选更透明 | 其余 36 帧都是 0%；3847 自身 0.1%（噪声） |

这是**整卷里观察到的最低密度**，它是片基密度的上界；只有当确实有帧碰到了未曝光区时，它才等于片基。
11 帧色度收敛，支持“已经碰到底”，但不构成证明。

**如果每帧各自估计片基：** 37 帧里有 24 帧的通道间色偏超过 0.03 D（约 7% 的通道比例差），R−G 中位数 −0.058 D，
最严重的是 3822（−0.17 D）。整卷片基消除了这一项。

## 5. 已知问题：片基和黑点绑在一起

现在引擎默认黑点 = 片基（`d_lo = 0`）。用整卷片基之后，没碰到底的帧最暗处也高于黑点，画面会变平、暗部发灰。
例如 3826，它的最低密度比底高 0.46 D，用整卷片基后画质检查报“影调范围不足”。目视对照（`previews/`，不进 git）：

- 3826：本帧自动估计的反差正常，整卷片基的明显偏平。
- 3838、3855：两者差别不大，整卷片基的稍平。

`InversionParams` 已经有独立的逐通道黑点 `d_lo`，只是管线没有暴露。合理的做法是：整卷片基负责颜色参照，
每帧再设一个**中性**黑点（三个通道同一个偏移）负责影调。这等于在参数体系里加一个自动参数，留给 S2-7
（无参考优化器）决定，这一单元不改引擎。

**颜色是否更准，这一单元没有证明：** 店家图的调色幅度很大，用它判断片基选得对不对，要等拟合和评估（S2-6、S2-7）。
