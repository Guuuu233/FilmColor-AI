## 1. 现行反转，按代码写（`invert.invert_negative`、`scripts/diag_common.positive_T`）

记扫描的线性信号为 T_c(x)，c ∈ {R, G, B}，并令 L_c(x) = −log₁₀ max(T_c(x), ε)。

- 片基 b 的密度：D_c = L_c + log₁₀ b_c。
- 黑点 d_lo = 0；白点 d_hi,c = p_hi,c + log₁₀ b_c。其中 p_hi,c 是画面区域内 L_c 的 99.9 百分位，与 b 无关。
- 归一化：s_c = (D_c − d_lo,c) / (d_hi,c − d_lo,c)。
- 正片：P_c = (10^{k(s_c − 1)} − 10^{−k}) / (1 − 10^{−k})，k = (d_hi,G − d_lo,G) / γ，γ = 0.6。三通道共用同一个 k。

两点和任务单写法不同的地方，以代码为准：

- 曲线不是 u^γ。
- 正片这一步不裁切：比黑点更透明的像素给出 P_c < 0，渲染时才压到 0。

**引理（片基只通过黑点进入反转）。** 代入以后：

s_c = (L_c − λ_c) / (p_hi,c − λ_c)，λ_c = −log₁₀ b_c，k = (p_hi,G − λ_G) / γ。

所以片基向量 b 对反转的全部作用，就是给出每个通道在 L 空间里的黑点位置 λ_c；白点 p_hi,c 来自画面本身。任何“片基 / 黑点”变体都可以写成一个三维黑点 λ，等价地写成一个“有效片基” b_eff = 10^{−λ}，然后原样调用现有的反转。**因此本实验不需要改引擎**，变体只是换一个传给现有函数的片基向量。

把 λ 写成亮度和色度两部分：λ_c = −(ℓ + c_c)，其中 ℓ 是三通道 log₁₀ b 的平均，c 是色度偏移，满足 Σc = 0（与 `sep_check.split` 相同）。

## 2. 变体（每个都只是一个 b_eff）

| 名称 | b_eff | 说明 |
|---|---|---|
| **B0** | 逐帧自动片基 b₀（第一层是只在 `IMAGE_BOX` 内搜索的 b_int；第二、三层是引擎的 b₀，即 `base_cache`） | 现行基线，硬黑点 |
| **BM** | 片边实测 b_meas | 只在第一层；作为物理基准渲染 |
| **B1** | 整卷片基（第一层：同组 b_int 的 `estimate_base_roll`；第二、三层：`s3_separate` 已有的整卷片基） | 已有的完整替换，只作对照，不是新设计 |
| **L0C1_hard** | 10^{ℓ₀ + c\*} | 亮度取逐帧 ℓ₀，色度取候选 c\*；上一轮失败的那种 |
| **DQ(c\*)** | 10^{c\* − d_lo}，其中 d_lo = min_c [ P_q(L_c) + c\*_c ]，q = 0.1 % | **新设计：分位数共享黑点** |
| **DQ(c₀)** | 同上，c\* 换成本帧自己的色度 c₀ | 对照：只换黑点规则、不换色度 |

**DQ 的含义。** 记 D̃_c = L_c + c\*_c（去色罩后的相对密度，只依赖色度 c\*，不依赖亮度 ℓ）。三通道共用一个黑点 d_lo，白点仍是各通道自己的 99.9 百分位。这正是任务单里的“共享分位数黑点”。代入引理：

- λ_c = d_lo − c\*_c，也就是 b_eff 的色度等于 c\*，亮度等于 −d_lo，由画面本身决定；
- 物理上，这是“色度为 c\* 的、**不比画面上任何通道的最薄 0.1 % 像素更密**的最密片基”。

**DQ 的几个性质（在跑数据之前就成立）：**

1. **截断有上限。** 在算分位数的同一组像素上，取到最小值的那个通道恰好 q 的像素落到黑点以下，其余通道少于 q。所以 §4 第 1 条（截断）对 DQ 基本是机械成立的，只是实现检查，不能算证据。在评价网格上算的比例会稍有不同，因为网格和算分位数的区域不同。
2. **色度保留。** 三通道减去的是同一个标量 d_lo，所以 c\* 造成的通道间偏移完整保留。
3. **亮度换成了自动定级。** 片基亮度 ℓ 不再进入公式，换成了画面最薄部分的位置 −d_lo。
   - 画面里有接近片基的区域（深阴影）时，−d_lo 接近真实片基的亮度。
   - 画面里没有这种区域时（高调、雾、低反差场景），黑点会落到画面最暗的内容上，相当于“自动色阶”：阴影被拉黑，反差变大。**这是 DQ 的已知风险**，第一层用实测片基渲染作为基准，可以直接看出来。
4. **DQ(c₀) ≈ B0。** 帧内有接近片基的区域时，b₀ 取的是最亮的均匀块，P_q 与 −log b₀ 接近，所以 DQ(c₀) 应当接近 B0。DQ(c\*) 与 DQ(c₀) 的差别，就是“换色度”本身的效果；DQ(c₀) 与 B0 的差别，就是“换黑点规则”本身的效果。

**不纳入 D_soft（平滑趾部）的理由。** 趾部宽度是一个自由参数，没有数据就定不下来，违反“没有看结果调出来的自由参数”。而且 DQ 已经把截断限制在 q 以内。如果研究方要纳入，需要先给出趾部宽度的定值。

**c\* 的来源：**

| 层 | c\* |
|---|---|
| 第一层 | c_meas（片边实测的色度）；同组多帧时另测 c_roll_int（只看画面内部的整卷色度） |
| 第二、三层 | c_roll（`s3_separate` 已算好的整卷片基色度，不重算） |

**分位数和白点取在哪里：**

- 第一层：全分辨率、`IMAGE_BOX` 内、不饱和像素的 L 百分位，由 T3a 存在 `rebate_verified.json` 的 `L_percentiles_box`，p_hi 用 99.9，P_q 用 0.1。
- 第二、三层：`s3_diag` 记录里引擎区域（中央区域、不饱和）的全分辨率 `L_percentiles`，p_hi 用 99.9，P_q 用 0.1，与 `sep_check.py` 的白点同源。

## 3. 数据、读法、指标

### 第一层（主评价，物理参照）：T3a 合格的片边帧

- **范围：** 合格帧清单经研究方和用户核对 ROI 拼图后确定。
- **输入：** 算法只看 `IMAGE_BOX` 内的像素，也就是 1/8 缓存里落在框内、不含饱和块的部分。
- **c\*：** 所有合格帧测 c_meas；T3a 形成的同组帧（同机身、同日、同 ISO、同光圈、同镜头、同索引胶片，≥ 3 帧合格）另测 c_roll_int。
- **读法：**
  - 固定观感：`global_look_v1`；
  - 明度对齐：只调 ev，ev 在 `BOUNDS["ev"]` 内二分 30 次，使该帧像素上的 L\* 中位数等于 **BM 在固定观感下的 L\* 中位数**。BM 是物理基准，不是人工参考。
- **指标（每个变体相对 BM 渲染，同一读法）：**
  - ΔE2000 中位数；
  - a\*b\* 距离中位数；
  - 固定观感下 L\* 中位数之差的绝对值 |ΔL\*|；
  - `below_black_any`（任一通道 P < 0 的像素比例）和各通道的 `below_black`。

### 第二层（无参考诊断）：`s3_separate` 的三组开发数据

- **数据：** S3 诊断三卷 109 帧、v1 两卷 42 帧、BlueNeg 107 帧。T8 网格、配准和整卷片基全部沿用，不重算。c\* = c_roll。
- **指标：**
  - `below_black_any`；
  - 高光裁切：固定观感下，渲染前任一通道 > 1 的像素比例（`diag_common.metrics` 的 `clipped_frac`）；
  - 固定观感下，相对 B0 的 L\* 中位数之差 |ΔL\*|。

### 第三层（次要，含调色者风格）：上述有参考的帧

- **读法：** 固定观感、明度对齐（目标为 B0 固定观感的 L\* 中位数，与 `s3_separate` 相同）、P4。
- **指标：** 相对人工参考的 ΔE2000 中位数和 a\*b\* 距离中位数。店家和用户分开列。
- **分组：** 按逐帧与整卷片基的色度差 ΔC（`chroma_part`，即 max_c |c₀,c − c_roll,c|）≥ 0.1 D 和 < 0.1 D 分开列。
- **用途：** 只用于确认“片基误判帧上颜色方向改善、正常帧上不退化”。不拿小的 ΔE 差当唯一判据。

**无定义：** 正片不是有限值的变体记为无定义，单独计数，在“变差”的统计里算作变差（与 `s3_separate` 相同）。

## 4. 通过标准（事先写定）

带 \* 的阈值是执行者提议的，待研究方确认。

1. **消除截断（任务单原文）。** 第一层和第二层所有帧上：DQ(c\*) 的 `below_black_any` 中位数 ≤ 0.5 %，单帧最大 ≤ 2 %。按 §2 性质 1，这条主要是实现检查。
2. **第一层，c\* = c_meas。**
   - (a)\* DQ(c_meas) 相对 BM 的明度对齐 ΔE2000 中位数（各帧中位数再取中位数）≤ 2.0。
   - (b)\* 在 “B0 偏离帧” 上，DQ(c_meas) 的明度对齐 ΔE 低于 B0 的帧数 ≥ 2/3，且 ΔE 下降量的中位数 ≥ 1.0。“B0 偏离帧” 指 B0 相对 BM 的明度对齐 ΔE ≥ 2.0 的帧，按 B0 的结果定义，与 DQ 无关。
   - 偏离帧少于 5 帧时，(b) 记为“样本不足，不判”，不算通过。
3. **第一层，同组帧，c\* = c_roll_int。**
   - (a)\* 明度对齐 ΔE（相对 BM）的组内中位数：DQ(c_roll_int) < B0；
   - (b)\* 固定观感 ΔE（相对 BM）的组内中位数：DQ(c_roll_int) < B0。固定观感包含曝光，所以这一条同时检查亮度有没有像 B1 那样大幅漂移。
   - B1 和 L0C1_hard 并列报告。
   - 没有合格的同组时，本条记为“无样本，不判”。
4. **第二层，亮度稳定\*。** 每个数据集上，DQ(c_roll) 相对 B0 的固定观感 |ΔL\*| 中位数 ≤ 2.0，而且小于 B1 的同一数值。
5. **第三层，正常帧不退化（任务单原文）。** 范围：S3 诊断三卷中 ΔC < 0.1 D 的帧、v1 两卷全部帧、BlueNeg 10 卷全部帧。每卷中，固定观感下 DQ(c_roll) 相对 B0 的 ΔE2000 中位数变差超过 2 的帧（含无定义）≤ 1 帧。

**怎么用结果：**

- 1～5 全部通过：DQ 可以作为“实验性选项”提给软件（界面上与现行反转并列，由用户选），不改默认，不自动切换（与 R1 的处理一致）。
- 任何一条不通过：不进入软件，报告哪一条、在哪些帧上失败。
- 第 2 条 (a) 通过而 (b) 不通过，说明 DQ 本身不引入损失，但在片基误判帧上收益不够。
- 第 3 条不通过而第 2 条通过，说明问题在整卷色度估计，不在黑点规则。
