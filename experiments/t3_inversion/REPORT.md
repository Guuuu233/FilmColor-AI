## 6. 对下一步反转设计的物理启示（仅作诊断总结，不自动入库）

1. **共享黑点解耦在“画面有真实暗部、或者片基色度与最薄像素一致”时完全成立：**
   - 第一层物理参照（第 2、3 条）全部通过，`DQ(c_meas)` 将 25 帧相对 `BM` 的明度对齐 $\Delta E_{2000}$ 中位数压到 **0.702**（干净子集 26 帧为 **0.467**），且消除了 `A034` 的无定义溢出和 `L0C1_hard` 的 50%+ 截断。
   - 在用户调色参考的 25 个片基误判帧（$\Delta C \ge 0.1\text{ D}$）上，`DQ(c_roll)` 固定观感 **25/25 全胜 `B0`（中位数 −10.97 $\Delta E$）**，P4 可表达性中位数从 `B0` 的 $10.13$ 降到 **$4.65$**（优于 `B1` 的 $5.30$）。
2. **为什么无条件取 $d_{\text{lo}} = \min_c P_{0.1\%}(\tilde{D}_c)$ 在第 4、5 条失败：**
   - 当一帧画面**没有接近片基的深暗阴影**（如 `A1020` 纯雾景、或 `Gold 200` / `199412E` 的高调日景）时，画面最薄处的密度 $\min_c P_{0.1\%}(\tilde{D}_c)$ 实际上是某个带色彩的中间调（比真实片基高 $+0.2\sim +0.5\text{ D}$）。
   - 无条件把 $d_{\text{lo}}$ 提到 $\min_c P_{0.1\%}(\tilde{D}_c)$ 会把该通道的最亮阴影硬拉成纯黑 $0$（自动色阶效应），既改变了正常帧的曝光/反差（触发第 4、5 条），又在单通道先触底时扭曲了雾景/高调帧的阴影颜色（`A1020`）。
   - **关键改进方向（留待下一轮讨论）：** 逐帧自动片基的亮度水平 $-\ell_0$ 只有在“替换色度 $c_*$ 后确实会导致某通道越过黑点（即 $\min_c(P_{0.1\%}(L_c) + c_{*,c}) < -\ell_0$）”时才需要下移兜底！也就是说，若取**单侧保护黑点** $d_{\text{lo}} = \min\!\big(-\ell_0,\, \min_c(P_{0.1\%}(L_c) + c_{*,c})\big)$（只下移防截断、绝不上提拉黑正常高调帧），正常帧和 `A1020` 上的自动色阶副作用是否就能从机制上避免？这留给研究方与用户审阅本报告后决定。

### 6.1 2026-10-23 研究方复核更正（对上文“单侧保护黑点”归因的实测纠偏）

研究方对 314 个任务 JSON 做了独立核查与重算（`FilmColor_AI_T3b复核与下一步决定_2026-10-23.md` §3），指出了上文第 2 点归因的两处事实错误，特此更正留档：

1. **在 314 个任务中，有 285 个任务（90.8%）本来就满足 $d_{\text{lo}}(c_{\text{roll}}) = \min_c(P_{0.1\%}(L_c) + c_{\text{roll},c}) \le -\ell_0$：**
   - 因此单侧公式 $\min(-\ell_0,\, d_{\text{lo}}(c_{\text{roll}}))$ 在 90.8% 的任务上恒等于 $d_{\text{lo}}(c_{\text{roll}})$，与已跑完的 `DQ(c_roll)` 输出逐位相同。
   - 在违反第 5 条最多的 `Gold 200`（全部 17 个店家任务、3 个用户任务，如 `A224_shop`：$-\ell_0 = 1.2188$，$d_{\text{lo}}(c_{\text{roll}}) = 1.1610 < -\ell_0$）以及第一层 `A1020`（$-\ell_0 = 1.1985$，$d_{\text{lo}}(c_{\text{meas}}) = 1.0493 < -\ell_0$）上，`DQ` 并非把黑点“上提拉黑”，而是把黑点**下移了约 $0.06\text{ D}$**，使 `A224` 中位亮度 $L^*$ 从 `B0` 的 $33.5$ 提亮到 $43.4$。
   - **真正原因（尺度不一致与蓝通道单像素散粒噪声）：** `b0` 是在超像素块均值上取的最透块，而第二层复用的 `trec["L_percentiles"]["0.1"]` 是在全分辨率**单像素**上取的 $0.1\%$ 分位数。负片蓝通道受橙色色罩吸收最暗，单像素散粒噪声使 $0.1\%$ 极端亮点比 $48\times 48$ 块均值偏低中位数 $-0.041\text{ D}$（314 个任务中有 185 个由 B 通道单像素噪声决定 `argmin`）。将分位数 $P_{0.1\%}(L_c)$ 改为在**全画面有效掩膜的 $48\times 48$ 超像素块均值 `sp`** 上计算后（与 `b0` 同尺度、同掩膜），`A224` 上的 $d_{\text{lo}}(c_0) = 1.2183$、$d_{\text{lo}}(c_{\text{roll}}) = 1.2150$，与 $-\ell_0 = 1.2188$ 的差距缩小到 $\le 0.004\text{ D}$，同时一次性消除了第 1 条的中央 25% 窗口错位与第 4、5 条的单像素散粒噪声下移。
2. **在 `DSC_3827`（`shop_r01`）和 `19941222E-01-nara`（BlueNeg）上，退化来自替换整卷色度 $c_{\text{roll}}$ 本身：**
   - `DSC_3827` 上 `B0`（$13.10$）与 `DQ(c0)`（$14.20$）接近，而只要换入 $c_{\text{roll}}$，`B1`（$22.51$）、`L0C1_hard`（$23.90$）、`DQ(c_roll)`（$22.69$）均偏离参考约 $9\,\Delta E$。这证明正常帧不应后台全自动强制替换为整卷色度，默认仍应保持本帧自动 `B0`，而把 `DQ(c_roll)`（$48\times 48$ 块均值版）作为界面上的片基模式选项供用户在异常帧上切换。
