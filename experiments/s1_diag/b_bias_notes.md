# 分析路径与渲染路径的通道偏差（2026-10-14）

现象：12 张 X-T2 样本上，渲染路径（LibRaw 默认 X-Trans 反马赛克）与分析路径（CFA 分色块均值）的 48×48 块均值之比，R 1.0002～1.0014、G 0.998～0.999、B 1.002～1.008（`dual_path.json`）。

排查（脚本见 `scripts/diag_b_bias.py`、`diag_demosaic_algos.py`、`diag_cfa_position.py`）：

1. **原生采样点**：渲染值 / 原始线性值在 R、G、B 自身 CFA 位置上 100% 在 ±0.1% 内（_DSF9235、_DSF9228）。→ 黑电平与缩放正确，偏差只来自插值点。
2. **按纹理分组**：B 偏差在最平坦到最多纹理的四分位都在 1.0058～1.0071（_DSF9235）。→ 不是边缘插值误差。
3. **按信号强度分组**：B 从最暗四分位 1.0079 到最亮 1.0056，变化小。→ 噪声引起的方向选择偏差不是主因。
4. **换算法**（_DSF9235）：默认 X-Trans 算法 R/G/B = 1.0005/0.9985/1.0066；LINEAR 0.9982/0.9997/0.9980；VNG 0.9983/1.0002/0.9986。→ 偏差依赖算法。
5. **同色不同位置的感光**：在平坦片基块上，6×6 排列中同色各位置的均值相差 R 1.1～1.2%、G 1.3～1.7%、B 0.5～0.9%（3 张一致；每位置约数千个采样，噪声解释不了）。

结论：同色像素在不同 CFA 位置的感光不完全相同（推测为相邻像素串扰差异，未验证），不同反马赛克算法给各位置的权重不同，因此通道均值有 ≤ 0.8% 的算法相关差异。不是 bug。折合密度约 0.003 D，视觉上不可见。

对设计的影响：片基与画面必须在同一信号上测量（`invert.base_from_regions` 在渲染信号上取片基），否则两者相除会引入固定的通道偏差。
