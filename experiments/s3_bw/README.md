# S3-4 黑白负片回归样本

代码 `b549768`。两张都已登记的黑白负片，分别用 `--auto --film bw` 和 `--auto --film color` 转换（`bw/`、`color/`，TIFF 不进 git）。

| 画格 | 来源 | 模式 | 画面中心 50% 的平均 C*ab | p95 | 平均 a* / b* |
|---|---|---|---|---|---|
| DSC03060 | nlp_forum_9652（Sony A7R II，VALOI 360） | color | 10.20 | 15.07 | +1.29 / −9.92 |
| DSC03060 | 同上 | bw | 0.02 | 0.02 | +0.01 / −0.01 |
| _DSF9228 | nlp_official（Fuji X-T2） | color | 4.80 | 8.09 | +0.77 / −4.67 |
| _DSF9228 | 同上 | bw | 0.02 | 0.02 | +0.01 / −0.01 |

Lab 由 `compare.load_lab` 按输出文件里嵌的 ICC（未校准的设备 RGB，按 sRGB 原色解读）计算，降采样 8 倍。bw 模式下剩下的 0.02 来自 16 位量化和 ICC 转换，三个通道的像素逐值相等（`tests/test_bw.py`）。

目视对比（不进 git）：黑白模式下两张都是中性灰。Sony 这张比 Noritsu 扫描略暗、反差略高；9228 比 NLP 的版本更暗、雾感更轻。影调差异没有做数值评估。
