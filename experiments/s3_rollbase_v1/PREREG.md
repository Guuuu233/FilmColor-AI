# 卷级片基验证 v1：预登记（2026-10-18）

本文件在处理任何验证数据之前写成并提交，提交的 commit 就是时间戳。写本文件时，没有读过 `dsc6233`、`shop_r01` 的任何片基、EXIF、图像或成品。结果无论好坏都按本文件报告，不改规则、不调阈值。

## 1. 背景

上一轮诊断（`experiments/s3_diag/REPORT.md`，commit `fc8b474`，审查通过）在 `dsc6161`、`dsc8242`、Gold 200 三卷上发现：

- 逐帧片基把有颜色的景物当成片基时，会出现严重偏色。
- 用整卷片基的**完整 RGB 向量**替换逐帧片基（B1）可以纠正。
- 只换颜色、不换绝对水平的 B1c 失败了。
- 0.1 D 色度差分界是看过结果后定的。

本轮在**没有参与片基诊断**的两卷开发数据上检验这条规则。它们都参与过 S3 的机器学习实验，所以本轮属于进一步的开发验证，不是最终独立验证。

## 2. 规则（锁定）

对一卷里每一帧：

- `b_own`：S3 缓存记录的逐帧自动片基（渲染路径，即正式引擎 `pipeline.positive` 用的片基）。
- `b_roll`：`filmcolor.base.estimate_base_roll`，参数全用默认值（`level_window=0.1`、`chroma_tol=0.05`、`n_use=3`、`min_members=3`）。输入是本卷全部开发帧的 `b_own`，按 EXIF `ExposureTime`（标称值）归一化，和 `diag_roll_base.py` 完全相同。
- 色度差 `c = max(|o_R − o_G|, |o_B − o_G|)`，其中 `o = log10(b_roll(t) / b_own)`。
- **规则 R1**：`c ≥ 0.1` 时，该帧用 `b_roll` 的完整 RGB 向量作为片基（黑点 = 片基，白点 = 全分辨率 L 的 99.9 分位 + log10 片基，即 B1）；否则用 `b_own`（B0，即现有引擎）。

适用条件（任何一条不满足，整卷 R1 = B0，并如实报告“不适用”）：

- 本卷各帧的 FNumber、ISO、LensID 必须一致；
- `estimate_base_roll` 必须成功。

估计有警告（簇成员 < 3）时照常执行，单独标出。

## 4. 比较的反转

- **B0**：现有引擎。
- **R1**：上述规则。**这是决策对象。**
- **B1**：所有帧都用整卷片基，作对照，不参与决策。

每种反转都配以下三种参数：

- 固定风格 `global_look_v1`，**无参考，主要指标**；
- P4 标签（`fit_config_s3_p4`，看参考图，只作可表达性诊断）；
- ub7 上限（只作诊断）。

## 5. 指标

逐帧报告：

- ΔE2000 中位数；
- 明度误差 ΔL 中位数；
- 色相偏差 |Δh| 中位数；
- 按参考明度分暗部、中间调、高光三段的 ΔE2000；
- 各通道落到黑点以下的像素比例；
- 高光裁切比例。

逐卷报告：

- 触发率；
- 主要指标的逐帧差 `Δ = ΔE_fixed(R1) − ΔE_fixed(B0)`：全部帧和触发帧的中位数、变好的帧数；
- 最差 3 帧，附目视对比图。

不报告跨卷平均的显著性。

## 6. 通过标准（锁定）

- **严重退化**：某帧 `Δ > +2.0`。
- **新增裁切**：任一通道落到黑点以下的比例比 B0 高出 2 个百分点以上。

逐卷判定：

1. **触发 ≥ 3 帧的卷**，要同时满足：
   - 触发帧的 `Δ` 中位数 < 0；
   - 触发帧中至少 2/3 变好（`Δ < 0`）；
   - 严重退化不超过 1 帧；
   - 全部帧的 `Δ` 中位数 ≤ +0.1。
2. **触发 < 3 帧的卷**：不提供有效性证据，只检查危害，要求严重退化 0 帧、新增裁切 0 帧。

**本阶段通过**的条件：

- 两卷都满足各自的判定；
- 至少一卷属于“触发 ≥ 3 帧”。

如果两卷都触发不足 3 帧，结论是“证据不足”，不是“通过”。

**通过后**，也只是进入下一步讨论（是否在封存集上做一次性检验、是否进引擎），不直接改引擎。**未通过**也照常报告，并分析失败的帧。

## 7. 片基估计稳定性（已完成，只用上一轮诊断卷的负片数据）

`scripts/rb_stability.py` 的输入是 `experiments/s3_diag/roll_base.json` 记录的逐帧片基和快门时间，结果在 `stability.json`。

- **`dsc6161`**：整卷片基只由 A012、A021、A022 三帧决定，簇成员也正好 3 个。
  - 轮流去掉任一会改变结果的帧（A012、A021、A022，以及会移动簇中心的 A023、A024、A035）：片基水平最多变 0.035 D，颜色最多变 0.02 D；37 帧中只有 A015（色度差约 0.11）会跨过 0.1 D 分界。上一轮要纠正的逐帧误差是 0.6～0.74 D、颜色 0.2～0.3 D。
  - 但簇很脆：颜色容差减半（0.025）时找不到一致的簇，估计失败；去掉 A012、A021、A024 或 A035 中任一帧，簇都只剩 2 帧并触发警告。
- **`dsc8242`**：去掉 A141 或 A123 时水平变 0.05 D、颜色 ≤ 0.013 D，有 2 帧跨过分界。
- **Gold 200**：簇有 26 帧，任一帧的去留都不超过 0.004 D。
- **快门归一化**：三卷光圈、ISO、镜头一致，快门不同（`dsc6161` 在 1/40～1/13 秒之间，差约 0.49 D）。尼康 EXIF 记的是标称值（1/15 实为 1/16 秒），换成真实的 1/3 档值后，片基水平最多变 0.028 D，颜色基本不变。归一化误差三通道同比例，只影响绝对水平，不影响色度判定。
- **光源稳定性**：无法直接验证，没有片边，也没有背光参考帧。间接证据是两卷 5207 隔 9 天翻拍，整卷片基颜色差约 0.02 D、水平差 0.07 D，没有看到大的变化；同一卷之内的漂移测不出来。

这些片基变化对图像的影响（重渲染后固定风格的 ΔE 变化），要等缓存恢复后补算。
