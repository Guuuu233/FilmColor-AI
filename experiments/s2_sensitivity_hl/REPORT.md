# S2-6 高光裁切约束：三模式重跑与正则 / 高光权重敏感性

参考图拟合器仍是研究工具（看得到 NLP 结果），只用来检验参数表达能力和参数标签的约定，不是自动校色基线。
ΔE2000 是相对 NLP 输出的差异（我们这侧未做色度校准，按 sRGB 原色解读），不是颜色准确度。

## 背景

S2-3 发现拟合器会牺牲高光：`_DSF9237` 把 18.9% 的画面推成纯白（NLP 0.5%），因为 CIEDE2000 对
“纯白 vs 浅灰”只罚 2～3。S2-6 在目标函数里加了高光惩罚（定义见 `src/filmcolor/fit.py` 文件头）：
对裁切前超过白点的部分按“超出档数”计罚（平滑折线 h(s)=√(s²+δ²)−δ，δ=0.05 档），
参考图自身已裁切的通道不罚。权重 `highlight_weight` 单位为“每像素每档 ΔE”，默认 10。
`highlight_weight=0` 时与 S2-2 / S2-3 的拟合器相同。

下表的“裁切%”均指**参考图未裁切处**被我们推过白点的像素比例。

## 复现

- 三模式：`scripts/fit_nlp.py SIDECAR_DIR REF_DIR COMPARE_JSON experiments/s2_fit_hl`（输入与 S2-2 相同：Sprint 1 sidecar、NLP 默认参考、S1-9 对齐结果）。
- 敏感性：`scripts/sensitivity.py experiments/s2_fit COMPARE_JSON experiments/s2_sensitivity_hl s2-6`（120 次拟合，像素缓存与 S2-3 共用）。
- 运行时的拟合器代码即本单元提交的 `src/filmcolor/fit.py` / `render.py`（运行后未再改动）。
- 汇总：

```
uv run python scripts/summarize_highlight.py experiments/s2_fit experiments/s2_fit_hl experiments/s2_fit/cache
uv run python scripts/summarize_sensitivity_hl.py experiments/s2_sensitivity_hl/sensitivity.json experiments/s2_sensitivity/sensitivity.json
```

旧 / 新两组参数都在同一组对齐像素（`experiments/s2_fit/cache` 的 P8 / R8）上重新渲染比较。

- 7reg 在 9237 上仍有 3.6% 裁切，比无正则的 7 参数（0.1%）多，原因见下节。

## 二、正则强度扫描（高光权重 10）

| λ | ΔE 中位数 | 近优解离散 中位 / 最大 | 5 起点全近优的张数 | 碰边界 | 裁切% 最大 | 裁切 >2% 张数 | 无约束 S2-3：ΔE / 裁切% 最大 |
|---|---|---|---|---|---|---|---|
| 0 | 3.63 | 0.52 / 3.04 | 7 | 5 | 0.5 | 0 | 3.63 / 19.2 |
| 0.005 | 3.64 | 0.31 / 2.65 | 11 | 3 | 0.5 | 0 | 3.65 / 18.8 |
| 0.01 | 3.67 | 0.25 / 1.44 | 11 | 2 | 1.2 | 0 | 3.67 / 18.8 |
| 0.02 | 3.72 | 0.15 / 0.43 | 11 | 1 | 2.0 | 1 | 3.71 / 18.8 |
| 0.05 | 3.84 | 0.06 / 0.30 | 12 | 2 | 3.6 | 1 | 3.84 / 18.9 |
| 0.1 | 4.07 | 0.04 / 0.64 | 12 | 3 | 5.5 | 4 | 4.08 / 19.0 |
| 0.2 | 4.48 | 0.02 / 0.21 | 12 | 4 | 8.5 | 5 | 4.46 / 18.9 |

**正则和高光约束方向相反。** λ 越大，裁切越多（λ=0.2 时最多 8.5%，5 张超过 2%）。
推测（未单独验证）：正则把参数拉回默认值，而默认的高光压缩（shoulder）是 0，护高光需要把
shoulder 拉离默认值；高光惩罚是按全图像素平均的，几个百分点像素的裁切代价与 λ·Σu² 量级相当，λ 大时正则占上风。
ΔE 与稳定性随 λ 的变化与 S2-3 基本相同（ΔE 差 ≤ 0.02），即约束几乎不改变“稳定性 vs 误差”的取舍。

- λ=0.05 下，把高光权重从 10 提到 30，12 张中位 ΔE 不变，裁切最大值 3.6% → 1.6%，没有一张超过 2%，稳定性不变。
- 高光权重也会改变参数标签（8951 的 shoulder 变 0.97 个尺度单位）。和 λ、尺度一样，它属于必须一起固定的约定。
- 未测：hw=30 与其他 λ 的组合、hw > 30。

## 结论与建议

1. 高光约束有效且代价小，保留在拟合器里，后续无参考优化器也要带同样的约束。
2. 研究配置建议从“λ=0.05、hw=10”改为 **“λ=0.05、hw=30”**：误差和稳定性不变，裁切更少。备选是 λ=0.02、hw=10（ΔE 3.72，离散最大 0.43，裁切最大 2.0%）。
3. 正式冻结前还需要：hw=30 下补一次 λ 扫描（至少 0.02 / 0.05），确认推荐点不是孤立的；以及在第二种参考（店家 JPEG，`shop_r01`）上复核。
4. 默认值、正式参数范围都未改；默认参数输出与 Sprint 1 逐字节一致（测试锁定）。
