  - 变好：`_DSF8948` −2.96、A035 −2.33、199910-01-korea −1.75、A022 −1.04、A017 −0.65。
  - 变差：A030 +1.60、A010 +1.33、DSC_3838 +1.30、DSC_3839 +1.04、A208 +0.87、A199 +0.60、A015 +0.36。
- **变差的帧确实满足三项条件，不是实现错误。** 例如 DSC_3838 的 z0 [−0.17, +0.11]、z1 [−0.28, +0.15]、灰世界 [−0.42, +0.39]，A010 的 z1 [−0.19, +0.18]。这 7 帧的 Temp 从 T4h 的 +20～+32 被推到 +35～+50，其中 4 帧（A010、A030、A199、A208）推完后 db 为 +7～+18，画面偏黄。三区一致偏冷并不能把“负片色罩残留”与“画面本身偏冷”（阴天、雪景、蓝调室内）区分开。
- **任务单列出的全图冷偏帧里，A005、A006、A011 按任务单自己的阈值不会触发**，因为它们中调区的蓝轴是负的：

  - A011：z1 [−1.15, −0.28]

  它们在 T4i 里的改善（如 A006 15.36 → 12.83）来自 T4i 那条更宽的规则。A035 和 199910-01-korea 会触发，与任务单一致。
