## 已验证的结论

- 已复现 T4f：dsc6161 基准为 A012/A021/A022，RGB = [0.24104, 0.24285, 0.15213]，37 帧中标记 26 帧；A008 自动 Temp=0.0079、Tint=0.0244。
- 按 T4g 橙罩先验与全卷色度中心筛选后，候选池有橙罩帧 27/37（72.97%）；最终最透窄色度簇只有 A031/A009 两帧，RGB = [0.12241, 0.07897, 0.03178]，R/G=1.550、B/G=0.402。保留成员不足三帧的警告。不是任务单预举的 A026/A029/A030/A014。
- 不能从内部候选色度证明真实片基，更不能仅从候选颜色判断是镜头眩光。无片边条件下这仍是估计。
- 旧片基下 A008 的 d_lo_b1=0.62130、d_lo_used=0.84138，上拉 0.22008 D，与任务单这部分描述接近。黑点向上限幅 0.04 D 已实现，但新片基下 A008 的 d_lo_min=0.80964 < d_lo_b1=1.10871，实际使用防截断分支 d_lo=0.78964，向上限幅没有触发。不能把完整 T4g 的 A008 去青归功于这条限幅。
- 白平衡自适应低色度 15% + 中调 Huber 融合已实现；新片基下 A008 标准自动 Temp=+0.0271、Tint=+0.0029。没有复现任务单的 Temp=+0.50～+0.56。wb_max_shift=0.50 本身也限制了估计器的 Temp 上界（预设偏移另加）。
- A012 的五预设反差为 standard 1.40 / natural 1.18 / portrait 1.16 / vivid 1.56 / print 1.50。自然与人像在逆光上不再加反差；阴影、高光与乳剂斜率基线保留。
- **关键帧 ΔE 退步，尚不能声称主问题验收通过**：A008 标准 8.32→13.82，A012 4.09→6.76，A013 5.84→10.25，A019 15.68→17.05，A021 13.22→16.14。参考为原有 `04_已反转成品_对照答案`，不是任务消息中的截图或用户 +61/+14 手调成品。
- 图中 A008 青绿色偏减轻，但天空偏灰紫；A012 新片基下黑衣偏棕。风格表指定的人像参数已实现，不等于与参考一致或已经达到主观肤色目标。
- A008 单帧旧卷色度对照（保留旧 roll_rgb，启用新 0.04 D 黑点限幅、新 WB 和 T4g 标准表）：ΔE=8.63、mean da=-0.63、mean db=+8.68，Temp=+0.0519、Tint=+0.0573。完整 T4g 是 ΔE=13.82、da=+2.14、db=+18.07。支持本帧额外偏黄主要随新卷色度引入，但这只是开发帧消融，不能证明旧基准是真实片基。

## 实现与任务单的差异

1. 橙罩先验除占比 ≥25% 外，至少需要三个橙罩候选、且宽共识池至少三帧；不足时退回原来的最透窗口。原因：任务单字面算法在只有一张偏橙的浓密首帧时会选它作片基，真实 `test_own_roll.py` 回归已捕获。保留 `orange_mask_prior=False` 供关闭先验对照。
2. 目前橙罩共识卷自动使用 `roll_nat`，显式 `base_mode="auto"` 仍保留。原因：只改片基簇会使 A008 的 ΔC 从 0.2778 降到 0.0852（低于 0.10 阈值），原路由自动切回 B0；其本帧候选反转产生过黄与强反差。强制新整卷自然融合可避免这个问题。此接线扩大了默认使用卷级片基的帧数，需在全集结果中审查。
3. 任务单把橙色色罩称为必然物理先验；此处按任务单实现为可关闭的相机 RGB 启发式，不视为已用独立片边测量证明。
4. 没有读取任务消息中的 `artifact:` 链接；本地交付图来自仓库开发素材的实际渲染。未把研究方图例当作本轮实测。
5. 人像“淡黄”按表实现为全局饱和度、温偏和通道幂函数斜率，不是肤色分割或黄色专用色相控制。没有皮肤 ROI 标注、肤色 ΔE 或指定相纸/冲印机的标定，不能宣称复现富士/Noritsu/Kodak 的色彩科学。既有渲染器的 slope 是围绕中灰的相对幂函数，也不是由这卷实测得到的乳剂响应曲线。

## 验证协议

沿用 `scripts/t4d_source_eval.py`、`data/manifests/s3_dev_frames.json`：191 条开发帧，原有六张无 ICC 的 JPEG 排除，最终 185 条有效帧；NCC 阈值 0.7，四来源分别报告。对齐仍用每版自身正片的 `RenderParams()` 默认渲染，参数和搜索范围不变；本轮片基改变了正片。最终最低 NCC=0.8246，最大 NCC 变化=0.0256（A006）。两个评测半区无交叠、与完整清单一致。

ΔE 中位、均值、p90 均在各帧像素 ΔE2000 中位数上聚合；dL 是逐帧 mean_dL 的中位数。好/差以相对 T4f 标准的逐帧变化超过 0.25 为准。白平衡消融 `wb_t4f` 在同一 T4g 正片与标准表下关闭自适应和灰世界融合，不能称为整个 T4f 管线。

输入经过冻结集 guard（allow_frozen=False）；评估 JSON 附 RAW/参考 SHA256、Python/NumPy/平台版本、代码内容 SHA256。原片只读，未训练模型。
