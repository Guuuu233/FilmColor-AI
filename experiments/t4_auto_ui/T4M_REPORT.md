## 实施范围

1. `noref` 薄片：bright_share 门槛 .42，span_zero .46，ramp .16，EV cap 限于 [-.45, .60]；blacks_span .56、gain 1、max .20。薄片判据已满足且 span < .58 时逆光权重归零，诊断保留原权重。
2. `invert` 蓝白点护栏：保留三参数调用，新增四参数橙罩门控。App 默认 `(1.06, 1.18, .65, .48)`，以反演实际采用的 base 计算 B/G；显式白点重放不再次调整。
3. `noref` 青偏置信度：非 cool_cast、两个区域 narrow_share 均 < .04、综合色度 log2 R/G < -.85 时，confidence 至少 .72；记录 cyan_conf_boost。
4. `scanner` RGBI：接受 3/4 样本 LinearRaw，RGB 只用前三通道，IR 不参与饱和与片基统计；优先独立 IR 页面，否则记录 interleaved_4ch；保留 LUT 路径。
5. `holder`：默认双门限，保留边缘连通约束；大面积片夹用行/列非片夹占比 > .60 确定框。无有效比例框时退回原包围框，全片夹返回 None。Preview 外框涂灰只改变显示。
