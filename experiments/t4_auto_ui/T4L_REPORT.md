## 3. 与任务单预期不一致的事实与物理原因

1. **为什么 3.4 `self_ratio_white_point` 没有在 `DSC_3827`、`A006`、`A196` 上触发？**
   - 在 `invert_negative` 中，密度 `Dm = density(rgb[mask], base)` 是相对于**当前打开所用的片基 `base`** 计算的。
   - 第一阶段把 `ROLL_NAT_LEVEL_DIFF` 设为 `None` 后，`A006` 和 `A196` 打开时使用的是本帧 `B0`（`own_rgb`，落在画面内草地/路面暗部，红通道密度已被抬高）。在这个片基下，它们自身中调（`0.20..0.75 * d_hi_G`）的红绿密度比 `r_mid_R` 只有 `0.189`（`A006`）和 `0.124`（`A196`），比高光白点比 `r_hi_R`（`0.468`、`0.366`）更低，因此不满足 `r_hi < 0.78 * r_mid`。
   - 在 `DSC_3827` 上，本帧中调 `Dm` 的实测中位比是 `r_mid_B = 0.934`（任务单写的 `1.28` 接近整卷 `density_ratio`，而非本帧 `Dm` 在 `0.20..0.75 * d_hi_G` 的值），高光 `r_hi_B = 0.908 = 0.972 * r_mid_B`，同样高于 `0.78 * r_mid_B`。
   - 相反，该规则在 4 张 BlueNeg 开发帧（如 `19960809B-14`，中调 `r_mid_R = 1.552`、高光 `r_hi_R = 0.928`）上触发，把红通道白点抬高，导致 `19960809B-14` 从 `19.70` 退步到 `28.37`。在 123 帧 BlueNeg 检查集上，去掉反演层的改法（只保留 T4l 估计器改法）是 **10 好 / 4 差**（`13.93 / 14.47 / 20.84`），加上反演层后变成 `21 好 / 15 差`（均值 `14.53`、p90 `21.45`）。
2. **为什么 3.3 在 `_DSF9239` 上没有额外裁掉画格间黑缝？**
   - `_DSF9239` 的上下画格黑缝位于整张传感器图像的上下边缘，而测光掩膜 `mask` 默认只取中央 50% 窗口 `central_region(0.5)`，黑缝大部分已在窗口外，窗口边缘行不满足“整行 ≥ 80% 像素 ≤ 0.012”。`_DSF9239` 的改善（`21.74 → 10.32 → 10.12`）来自 T4k 的 `thin_neg_check` 与 T4l 的 `spike_clamp`。
3. **为什么 3.5a `ev_down_adaptive` 在自有素材上是 `3 好 / 9 差`？**
   - 自有素材（5207 电影卷与 Gold 200）中有 20 多帧反差较平，锚点曝光后纹理格的 `med_tex` 略高于目标带上限 `0.52`（如 `0.53..0.58`），同时纹理格 25% 分位 `q25_tex` 也在 `0.45..0.52`（因为画面反差小，而非全图过曝）。放宽 `dmax` 后，这些帧被压到 `med_tex = 0.50`，相比用户修图偏暗了 `0.1..0.3 EV`。如果只关闭 `ev_down_adaptive`（即 `no_ev_down` 变体），185 帧相对 T4k 为 **10 好 / 6 差**（自有素材 **5 好 / 2 差**）。
