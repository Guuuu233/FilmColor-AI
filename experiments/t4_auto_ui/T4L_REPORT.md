## 2. 默认开启的四项底层机制与默认关闭的两项开关

### 2.1 默认开启的四项净收益机制

1. **单通道黑电平读出噪声尖峰软限幅（`invert.clamp_spikes`，`app.SPIKE_CLAMP = (1.15, 0.12)`）**：
   - 当像素次密通道归一化密度 `s_mid <= 1.15`（画芯内部，非双通道远超白点的不透明片夹）时，限制单通道归一化密度不超过 `max(s_mid, 1.0) + 0.12`。
   - **实测效果**：佳能 5D Mark III `A1106.CR2` 的画芯蓝噪尖峰从 `11,462` 像素降至 `1` 像素，`holder_share` 保持 `0.2008` 完全不变，状态从 `manual_review_required` 恢复为 `ok`（`EV = -0.25, Temp = +7.0, Tint = +1.85`）；在 179 帧非 `self_ratio` 开发集帧上单独为 **5 好 / 2 差**，通过 `InversionParams.spike_clamp` 保证预览与导出一致。
2. **Adobe DNG `LinearizationTable` 查表线性化（`scanner.load_scanner`）**：
   - 在 BlackLevel / WhiteLevel 归一化前按 DNG 规范对整数像素查表展开，并在 `meta` 中记录 `linearization_table_len`。
   - **实测效果**：Plustek OpticFilm 8200i 8-bit 线性 DNG `A1283.DNG`（256 项 16-bit LUT，`WhiteLevel = 65535`）从抛 `ValueError` 恢复为正常打开（`status = ok`，`EV = -0.15, Temp = -12.4, Tint = +0.9`）。
3. **画芯测光掩膜（`noref._metering_mask`：`meter_holder_box=True` + `meter_trim_strips=True`）**：
   - 当 `holder_share >= 0.01` 时将测光框限制在 `film_box` 向内缩进 8% 的内框；并从上下左右向内裁除满足“该行/列掩膜像素 ≥ 80% 处 `max(RGB) <= 0.012`”的整行/整列贯穿式未曝光黑带（附加 2 行/列过渡余量）。
   - **实测效果**：在 `A012` 与 `A022` 等深色前景人像帧上裁除行/列数均为 **0**（100% 不伤前景）；在 185 帧开发集上裁除 8 帧（**4 好 / 2 差**：`19941218B-23` `12.82 → 11.33`、`19960812D-17` `14.65 → 13.62`、`A192` `4.91 → 4.16`）；在 123 帧 BlueNeg 检查集上裁除 14 帧。
4. **物理低信息失焦/空白帧拦截（`noref` `min_span_d_g = 0.22`）**：
   - 当反演绿通道物理密度跨度 `span_d_g < 0.22 D` 时标记 `low_information: density range ... < 0.22 D`，返回 `manual_review_required` 并在前端显示中文提示。
   - **实测效果**：准确拦截尼康 Z7_2 失焦废片 `A1141.NEF`（`span_d_g = 0.145 D`），185 帧开发集与 123 帧检查集正常帧 **0 误拦**。

### 2.2 默认设为关闭的两项开关（保留代码实现与显式传参测试）

1. **`app.WHITE_SELF_RATIO = None`**（原 `(0.78, 0.85)`）：
   - 单帧默认采用自身 `B0` 片基（`own_rgb`）时，`A006`、`A196` 的 `B0` 落在暗部草地/路面（红通道基底偏高），使单帧中调红绿密度比 `r_mid_R` 仅 `0.189` 与 `0.124`，未触发护栏；`DSC_3827` 单帧中调 `r_mid_B = 0.934`（高光 `0.908`）同样未触发；反而在 `19960809B-14` 上触发致 ΔE 从 `19.70` 退步到 `28.37`。关闭后 `19960809B-14` 立即恢复为 `19.71`，BlueNeg 开发集均值从 `13.91` 降至 `13.60`。
2. **`NOREF_V3["ev_down_adaptive"] = False`**（原 `True`）：
   - 自有素材（5207 与 Gold 200）中 20 余帧低反差画面在锚点曝光后 `med_tex` 仅略高于目标带上限（`0.53..0.58`），因反差小导致 `q25_tex >= 0.42` 被触发而多压暗约 `0.09 EV`（单独消融 `4 好 / 10 差`）。关闭后自有素材对 T4k 转为净正收益（`8.80 / 9.29 / 14.16`）。
