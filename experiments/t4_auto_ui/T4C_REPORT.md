## 1. 与任务单的偏差（需研究方确认）

1. **默认强度用 0.35 / 0.35，不是任务单的 0.65 / 0.65。** 0.65 / 0.65 在 9 帧上明显过饱和（色度比中位 1.25），
   ΔE 中位从 8.77 升到 10.06。0.35 / 0.35 是看了下表之后选的（开发帧上事后选择，只有 9 帧），与“矩阵 0.65、保色 0”
   的差别很小（8.15 vs 8.29），结论只是“0.65 / 0.65 太多”，不是“0.35 是最优”。滑条可调到 0～100。
2. **整卷中性比白点（2.3）已实现但不启用**（`invert.neutral_ratio_white_point`，`white_ratio` 默认 None；
   `/api/roll` 只报告比值）。两种接法在 9 帧上都更差（第 3 节），并且任务单“单一中性比 0.706 : 1 : 1.087”的前提
   与实测不符（第 4 节）。
3. **逆光规则（2.2）在 A019、A021 上不触发**：这两帧按编码输出算 p25 = 0.43 / 0.59、p90 = 0.64 / 0.80，不是
   “亮背景 + 暗前景”，它们与用户修图的差距是整体亮度（dL −17.6 / −19.3），不是逆光。
4. Midtone 滑条 UI 0 = 0.26（按任务单），但 NOREF_V3 的非逆光自动起点仍是 0.22（未改，改了会动所有帧的亮度）。

## 4. 中性比白点为什么不启用

`/api/roll` 的整卷比（0.25 ≤ D_G ≤ 0.75、卷底 B1）：dsc6161 **0.678 : 1 : 1.214**（大量蓝天，偏天空），
dsc6233 **0.748 : 1 : 0.904**（大量树叶，偏绿）。这个统计量取决于画面内容，不是染料的中性比。

- dsc6161 上，任务单点名的 A008、A012、A019、A021 都**不触发**（整卷比本身就偏天空：A008 本帧 B/G 1.233 未超过
  1.214 + 0.03，其余本帧 R/G 不低于 0.678）；只有 A034 触发，4.44 → 10.92（T4c 5.72 → 10.92）。
- dsc6233 四帧全部触发（整卷 B/G 0.904 偏绿），A081 15.19 → 10.88 变好，其余三帧变差，中位 9.03 → 12.00。
