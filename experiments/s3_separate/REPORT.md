## 0. 定义

**反转**（`diag_common.positive_T`，各变体相同，只有片基向量 b 不同）：

- 透射比相对片基：t = T / b；密度 D = −log10(max(t, ε))，逐通道计算。
- s = (D − d_lo) / (d_hi − d_lo)，其中 d_lo = 0，也就是“黑点 = 片基”。
- d_hi = L₉₉.₉ + log10 b。L₉₉.₉ 是该帧全分辨率 −log10 T 的 99.9 百分位，逐通道。
- 正片 P = (10^{k(s−1)} − 10^{−k}) / (1 − 10^{−k})，k = (d_hi,G − d_lo,G) / 0.6。
- 比片基更透明的像素（T > b）在该通道上 P < 0。正片这一步不裁切；裁到 [0, 1] 是在渲染（`render`）里做的。

**变体**：把 log10 b 写成 ℓ + c，ℓ 是三通道的平均，c 是各通道相对平均的偏差。

- B0 = 逐帧片基；B1 = 整卷片基。
- L0C1：log b = ℓ₀ + c₁，逐帧的亮度、整卷的颜色。
- L1C0：log b = ℓ₁ + c₀，整卷的亮度、逐帧的颜色。
- S3 诊断时的 B1c 是：片基用整卷的，黑点平移 c' = log10(b_roll,G / b₀,G)。它等价于片基 log b = log b_roll − c'，也就是颜色取整卷、G 通道的亮度取本帧。所以 B1c 和 L0C1 的区别只在亮度锚定在 G 通道，还是锚定在三通道平均。

**“黑点以下”**指配准网格上**至少一个通道** P < 0 的像素占比。网格是和参考图对齐后裁出的画面区域，没有再加其他掩膜。渲染后，这个通道会被压到 0，但不等于整个像素都是黑的。原报告写成“裁成全黑”是不准确的。

**三种读法**：

- **固定风格**：`global_look_v1`。
- **明度对齐**：除 ev 以外的 6 个参数都取 `global_look_v1`。ev 在 [−3, 3] 内二分搜索 30 次，使渲染结果在网格全部像素上的 L\* 中位数，等于 **B0 在固定风格下的 L\* 中位数**。整个过程不读参考图。315 条记录里，ev 一次都没有碰到搜索边界。B0 自己的明度对齐结果，就是它的固定风格结果。
- **P4**：参考拟合，只作诊断。

**指标**：相对参考成品的 ΔE2000 中位数，以及 a\*b\* 距离的中位数。参考成品是店家冲扫、你的调色或当年冲印，都是人为调色的结果，不是物理真值。

## 1. 结论（只适用于这次测试的变体、“黑点 = 片基”的约定和上面的明度对齐规则）

1. **只换颜色、只换亮度，在这次测试里都替代不了完整替换。**
   - 只换颜色（L0C1）：亮度停在逐帧那个过密的水平，至少一个通道比片基更透明。诊断三卷里逐帧片基偏离大的帧上，黑点以下（至少一个通道）的比例中位数是 53%（店家参考）和 64%（用户参考）。A034 一帧的 R 通道白点只比黑点高 0.02 D，反转结果没有定义。
   - 只换亮度（L1C0）：没有黑点以下的像素了，但相对参考的颜色误差没有降，明度对齐后反而比 B0 差。
   - 这只说明在“黑点 = 片基”的反转里，这两种拆法行不通。不能推出别的反转设计也分不开这两种作用，例如黑点和片基解耦的设计。那需要另外做实验。
2. **在以 B0 中位明度为目标的曝光规则下，B1 相对人工参考的剩余色差变化，因卷而异。**
   - 诊断三卷里颜色部分 ≥ 0.1 D 的帧：固定风格下 ΔE 中位数变化 −4.3（店家参考）和 −6.1（用户参考），明度对齐后是 −1.45 和 −3.1。用户参考的 25 帧里，22 帧变好，没有一帧变差超过 2。
   - 逐卷看，明度对齐后有明显改善的只有 `dsc6161`：店家参考 −0.67，用户参考 −1.13。Gold 200 对店家参考是 +0.72，有 8 帧变差超过 2；其他卷都在 ±0.4 以内。见 §3。
   - **原报告“约一半是真实颜色改善”的说法不成立，撤回。** ΔE 不能拆成可以相加的“曝光部分”和“颜色部分”。明度对齐也只是一种规则：它把中位明度对齐到 B0，不保证其他明度区域也对齐。参考是人工调色，不是真值。能说的只是：在这条规则下，相对这些参考仍有剩余的色差下降。
   - v1 两卷在这条规则下的变化接近 0（亮度部分 ≥ 0.1 D 的 21 帧：−0.005）。BlueNeg 没有下降（亮度部分 ≥ 0.1 D 的 6 帧：+1.04）。R1 当时触发的奈良、大阪两帧仍然变差约 2.4。这些结论只适用于这次的样本和规则。
3. **A7R5：6 帧中有 5 帧，B1 的渲染结果最接近 BM（实测片基）的渲染结果**，B1 的逐帧 ΔE 中位数在 0.98～1.26 之间（明度对齐口径）。例外是 DSC01688：颜色变体 L0C1 的 ΔE 为 1.04，略低于 B1 的 1.13（§4 表；10-22 更正，原写“6 帧上 B1 都最接近”）。这说明在这一卷、这个渲染配置下两者一致，不能单独证明最终颜色在物理上是对的。
4. **对片基颜色的敏感性**，在这次的样本和 `global_look_v1` 配置下：
   - A7R5 DSC01692、DSC01694 的逐帧片基，颜色部分只和整卷估计差约 0.03 D，渲染结果和 BM 就差 4.7 和 5.7 ΔE；
   - `shop_r01` 的 DSC_3827 颜色部分是 0.071 D，换成整卷片基后，a\*b\* 误差从 16.9 升到 27.0。
   - 这不能脱离具体样本和渲染配置去推广。

## 5. 局限

- 有参考的帧都是前几轮看过的开发数据。
- 明度对齐以 B0 为锚点，只对齐中位明度，只能比较变体之间的相对效果，本身不是一个好的自动曝光规则。
- A7R5 只有一卷、6 帧，没有参考成品；白点取自 1/8 缓存，不是全分辨率。
- 整卷片基沿用各轮已经算好的值，没有重新估计。

## 6. 对下一步的含义（建议，不是结论）

- **软件**：
  - 默认仍然用逐帧片基；
  - 整卷共享作为“实验性”选项，界面上显示逐帧片基和整卷片基的差值，由用户对比后决定；
  - 曝光单独提供调整，不靠换片基来间接改亮度。
- **研究**：
  - 黑点和片基解耦的反转，例如各通道单独定黑点，是否能把颜色和亮度的作用分开，是一个新问题，需要另立实验，并以实测片基为参照；
  - 目前能做这种参照的，只有 A7R5 一卷，以及群友素材里约 80 帧能看到片边的帧，而后者能不能用来测片基还没有核实。
