# 用户成片文件夹的核对（2026-10-17）

对象：`/Volumes/waizhiyingpan/照片`，用户的大部分成片（已去色罩），只读核对，没有移动、改名或写入。

## 结论

1. **冻结卷有另外的版本在这里**：#005 5219 小寨华山（39 张店家成品）和新疆/#011 5207（32 张用户自己的 Lightroom 调色，DSC_6200～6232）分别是冻结的 5219 卷和 5207 `dsc6199` 卷。共 71 个文件，已按 SHA256 补进冻结清单（`data/manifests/frozen_test_v1_photos.json`），冻结拦截会自动加载。
2. **同一批开发卷负片，还有用户本人的调色**：新疆/#012（`dsc6161`，37 张）、新疆/#007（Gold 200，20 张）。也就是说，同一批负片有店家调色师和用户两种成品，可以作为“个人审美”参考的现成来源，用途待定。
3. **逐字节相同的文件很少**：951 个文件里只有新疆/#008 的 20 张与 shop_r01 相同，其余同一画格的文件都是另外导出的。所以识别同一画格必须按内容比较，不能只看哈希。
4. **猜测被否定**：素材包 `dsc6161` 卷里那 6 张没有 ICC 的成品，不是用户的 Lightroom 导出。和用户对同一画格的调色相比，平均像素差是 14～38/255，和店家成品与用户调色之间的差距相当。来源仍然不明，继续按“sRGB 假设”标记，留在开发集里。

## 方法

- 清点：951 个文件、18 GB，全部计算 SHA256，并用 exiftool 读取尺寸、机型、软件和 ICC（原始输出在 `/tmp`，不进 git）。
- 按内容配对：`scripts/audit_photos_match.py`，方法和素材审计相同，比较亮度缩略图的相关系数，把每张照片和素材包的 397 张负片（取反）、284 张成品逐一比较（`match.json`；947 张参与，4 张非图片）。
- 冻结规则：`scripts/freeze_photos_addendum.py`。如果一个文件夹里不少于 80% 的照片以 r ≥ 0.9 匹配同一卷冻结卷，那么这个文件夹里最佳匹配是冻结画格的照片全部冻结。这样冻结的正好是 #005 和新疆/#011，共 71 个文件。
- 其余 43 张也以 r ≥ 0.75 匹配到冻结画格，但它们所在的文件夹不是冻结卷的副本。这 43 张都和匹配到的画格并排目视过（`outputs/frozen_candidates.jpg`，不进 git），没有一张是同一画格，只是明暗布局相似，作为“已拒绝的候选”记录在清单里。
- 其中有几张（例如新疆/#009 5294 的 DSC_3731，马群过河）和冻结的 5207 卷拍的是同一场景，属于同一次出行用另一台相机、另一种胶卷拍的。这是场景重叠，不是同一画格，和之前记录的冻结卷与开发卷之间的场景重叠是同一性质。
