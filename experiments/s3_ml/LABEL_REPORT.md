# S3 第 3 项：开发集 P 缓存和 P3/P4 标签的质量报告

日期 2026-10-17。设计见 `docs/S3_ML_DESIGN.md` 第 2.1 版。机器可读的汇总在 `label_report.json`（`scripts/s3_label_report.py`），逐帧标签在 `labels/<数据源>/<帧>.json`（`scripts/s3_labels.py`）。**冻结的两卷没有被读取，也没有生成它们的标签或缓存。**

## 结论

1. **P4 标签稳定，可以作为监督目标。** 5 个起点在每一帧上都收敛到同一个解：近优起点之间参数差超过 0.5 个尺度单位的帧，4 个参数都是 0%。ev 和 tint 从不碰边界；temp 有 8%（新胶卷）到 11%（BlueNeg）的帧碰边界。
2. **P4 的表达能力在大多数帧上够用，但不是全部。**
   - 从“固定观感”到“7 参数上限”的改善，中位帧上 P4 拿到了 86%～91%；P4 与上限在平均 ΔE 上的差，中位数是 0.33～0.64。
   - 新胶卷里有 27% 的帧差距超过 1，14% 超过 2。其中 15/18 个差距超过 2 的帧集中在一卷（5207 `dsc6161`），其余 3 卷 93 帧里只有 3 帧。
   - 也就是说，在这一卷上，即使模型完美预测出 4 个参数，也仍会有明显的误差。这是参数空间的限制，不是学习的问题。
3. **差距的两个来源**（目视最差案例，见下文）：
   - 固定的 contrast 2.0 和 sat 1.10（来自 `global_look_v1`）不适合调色师某些更平淡、更浅或更柔和的处理；
   - `dsc6161` 卷有随色相变化的偏色，全局参数无法消除。推断与片基误差有关（S3-5 的机理），**未验证**。
4. **P3 明显不如 P4**（新胶卷的平均 ΔE 中位数 5.49 对 4.37；P3 的 midtone 有 18% 的帧碰边界）。ev 需要逐张预测，P4 作为主变体是对的。
5. **新胶卷的标签主要是逐帧变化，不是逐卷偏移。** ev、temp、tint、midtone 的方差中，卷间部分分别占 29%、13%、13%、42%。不过 ev 的卷均值差别不小（−0.10 到 1.08），说明翻拍曝光逐卷不同，模型需要从画面统计里推断出来。
6. **7 参数标签不可辨识**：7 参数无正则的上限拟合，在 contrast、midtone、shoulder 上有 30%～60% 的帧出现“参数差很大、效果几乎一样”。这支持设计里用受约束标签，而不是 7 参数标签。

## 1. 做了什么

**输入 P 的定义**：新增 `pipeline.positive()`，返回 `convert` 渲染之前的线性正片：彩色模式、逐帧自动片基、white_pct 99.9、gamma 0.6、exposure 1.0。`convert` 改为调用它，改动前后，相机 RAW 在默认、auto 和黑白三种模式下的输出图像和 sidecar 逐字节相同。模型输入不经过任何渲染后的 TIFF，也不用参考图的任何信息。

**缓存**（`scripts/s3_build_cache.py`），放在外接盘 `$FILMCOLOR_DATA_ROOT/s3_ml/cache/`（这次是 `/Volumes/waizhiyingpan/filmcolor_data`，共 4.1 GB）：

- `X8`：整幅 P 的 1/8 块平均，是模型输入的来源，只依赖负片；
- `P8` / `R8`：对齐到参考图后的 1/8 网格，四周各裁 3%，只用于标签和评估；
- 不保存全分辨率 P。

数据根目录由环境变量 `FILMCOLOR_DATA_ROOT` 指定（`filmcolor.paths`），代码里没有写死盘名；没设置或目录不存在时直接报错，不会在内置盘上新建。每个缓存旁边都记录来源文件的 SHA256，读取时经过冻结拦截（`filmcolor.frozen`）。帧清单 `data/manifests/s3_dev_frames.json` 生成时整体核对过冻结集；每帧读取前又重新计算了一次 SHA256。

**对齐**：

- NLP 和店家：用现在的 P 按默认参数渲染，在内存里和参考图的 L\* 对齐，结果和 S1-9 / S2 的旧对齐**逐项相同**（11/11、21/21）；
- BlueNeg：沿用 S3-3 的配准，并重算了匹配分数（中位数 0.950，最低 0.811）；
- 新胶卷：匹配分数中位数 0.968，最低 0.794（A138）。最低的 A138、A140 在对照图里位置吻合，分数低是因为参考图的影调非常浅、和我们的差别大，不是错位。

**标签**（`scripts/s3_labels.py`）：每帧做 4 种拟合，另记录固定观感本身的误差：

| 名称 | 含义 |
|---|---|
| P4、P3 | `fit_config_s3_p4` / `_p3`，θ_fixed 取 `global_look_v1` |
| v1 | `fit_config_v1`（7 参数，λ=0.05） |
| ub7 | 7 参数全自由、无正则、高光约束相同，作为表达能力上限 |

**v1 不能当上限**：λ=0.05 会把 7 个参数都往引擎默认值拉，而 P4 固定的 contrast 2.0 离默认值 1.0 很远，所以 v1 在个别帧上比 P4 还差（A002）。因此另加了 ub7。

**冒烟测试**（BlueNeg、店家、新胶卷各一帧，在批量运行之前完成）：

- 两次运行的标签逐值相同；
- 用标签参数重新渲染，算出的 ΔE 与记录值一致；
- 通过 `convert` 用 P4 标签做全分辨率渲染，反演参数与缓存相同，店家和 BlueNeg 的画质检查通过，新胶卷 A002 给出 below_black 警告（见第 6 节）。

**规模和资源**：

- 帧数：A 59 帧；B 开发集 153 帧，其中 2 帧片基估计失败，实得 151 帧；
- 缓存构建：每帧约 20 秒，单进程峰值 3.50～3.75 GiB（`/usr/bin/time -l` 的 peak memory footprint）；
- 标签：每帧约 90～140 秒（6 个进程并行）。

有一次缓存构建的峰值是 6.58 GiB，超过了 6 GiB 的上限。原因是 6 张没有 ICC 的 JPEG 一次性按 float64 处理，改为分块和 float32 后，这 6 帧重新构建，峰值 3.75 GiB。

**与 S2 的差异**：S2 里 shop_r01 用的是卷级片基（`--roll-base`），这里按设计改为逐帧自动片基，所以店家帧的 P 和 S2 的缓存不同。

## 2. 表达能力：P4、P3 与上限

每帧取 ΔE2000 的中位数和平均值，表中是各组帧的中位数（中位 / 平均）：

| 组 | 帧 | 卷 | 固定观感 | P4 | P3 | v1 | ub7 上限 |
|---|---|---|---|---|---|---|---|
| A：NLP | 11 | 4 | 6.34 / 9.88 | 4.35 / 5.57 | 5.44 / 6.33 | 3.97 / 5.55 | 3.67 / 5.50 |
| A：店家 | 21 | 1 | 7.98 / 8.35 | 4.07 / 4.47 | 4.25 / 4.75 | 3.59 / 4.20 | 3.49 / 4.05 |
| A：BlueNeg | 27 | 23 | 11.08 / 12.92 | 6.82 / 7.71 | 7.15 / 8.40 | 6.44 / 7.25 | 6.07 / 6.99 |
| B 开发集（店家 + 新胶卷） | 151 | 5 | 10.34 / 11.20 | 3.74 / 4.38 | 4.29 / 5.34 | 3.28 / 4.11 | 3.18 / 3.99 |
| 新胶卷 | 130 | 4 | 11.53 / 12.63 | 3.68 / 4.37 | 4.50 / 5.49 | 3.25 / 4.11 | 3.13 / 3.98 |

P4 与上限的差距，按每帧的平均 ΔE 计：

| 组 | 中位数 | 90% 分位 | 差距 > 1 的帧 | 差距 > 2 的帧 | 中位帧上 P4 拿到的改善比例 |
|---|---|---|---|---|---|
| NLP | 0.39 | 0.56 | 0% | 0% | 86% |
| 店家 | 0.33 | 0.86 | 5% | 0% | 91% |
| BlueNeg | 0.63 | 1.68 | 19% | 4% | 89% |
| 新胶卷 | 0.64 | 3.00 | 27% | 14% | 91% |

拟合优化的目标是 pseudo-Huber 平均误差加高光惩罚，不是 ΔE 中位数，所以“差距”以平均 ΔE 和目标函数值为主，中位数作参考。A002 就是一个中位数和平均数结论相反的例子：参考图一部分区域吻合，另一部分差得很远。

**新胶卷逐卷**（每帧平均 ΔE 的中位数）：

| 卷 | 帧 | 固定观感 | P4 | 上限 | 差距 > 2 的帧 | 负片密度范围中位数 | 片基警告 |
|---|---|---|---|---|---|---|---|
| 5207 `dsc8242`（华山） | 37 | 12.12 | 4.26 | 3.83 | 2 | 1.40 | 24 |
| 5207 `dsc6161`（湖边、滑翔伞） | 37 | 17.43 | **8.81** | 5.82 | **15** | 0.99 | 14 |
| 5207 `dsc6233`（公园） | 21 | 14.68 | 4.57 | 3.95 | 0 | 1.96 | 5 |
| Gold 200 `dsc4889` | 35 | 8.53 | 3.79 | 3.52 | 1 | 0.85 | 5 |

没有 ICC、按 sRGB 读取的 6 张成品图都在 `dsc6161` 卷：P4 平均 ΔE 中位数 10.67，其余新胶卷是 4.32。差距中位数 3.25，其余是 0.62。这和该卷本身的问题混在一起，无法分开归因。

**最差案例目视**（`outputs/worst_ext.jpg`，不进 git）：

- A008、A019（`dsc6161`）：我们的反演把山体和地面渲染成浓重的橙黄，参考图是中性灰配蓝天。全局色温无法同时让橙色变灰、天空保持蓝色，上限只能靠降低饱和度折中。
- A138、A140（`dsc8242` 华山雪景）：参考图非常浅、对比低，是一种褪色感的处理；固定的 contrast 2.0 表达不了。
- A196（Gold 200）：参考图色彩柔和，固定的 sat 1.10 偏艳。
- A016（没有 ICC 的天空帧）：天空的明度和色相都有差别。

## 3. 参数碰边界

占各组帧数的比例：

| 组 | P4：ev / temp / tint / midtone | P3：temp / tint / midtone | ub7：contrast / midtone / shoulder |
|---|---|---|---|
| NLP | 0 / 0 / 0 / 9% | 0 / 0 / 9% | 27% / 9% / 18% |
| 店家 | 0 / 0 / 0 / 0 | 0 / 0 / 0 | 10% / 10% / 0 |
| BlueNeg | 0 / 11% / 0 / 0 | 11% / 0 / 11% | 30% / 4% / 56% |
| 新胶卷 | 0 / 8% / 0 / 4% | 7% / 0 / 18% | 12% / 23% / 44% |

temp 的边界是 ±1。碰边界的帧要求很强的冷暖修正，多数在 BlueNeg 和 `dsc6161`。

## 4. 多起点稳定性

- **P4、P3**：所有组里，每帧 5 个起点都是近优解（中位数 5），近优起点之间参数差超过 0.5 个尺度单位的帧占 0%。标签是唯一确定的。
- **ub7**：近优起点之间差超过 0.5 个尺度单位的帧，contrast 有 11%～31%，midtone 有 15%～45%，shoulder 有 30%～63%（随组不同）。例如 A002 的 5 个起点，目标函数值只差 0.03，ev 却从 0.25 到 1.6，contrast 从 0.81 到 1.24。7 参数空间里存在大片“不同参数、效果几乎一样”的区域。

|---|---|---|---|---|

| | temp | −0.22（−0.78～0.16） | 0.13 | −0.28、−0.35、0.06、−0.23 |
| | tint | 0.15（0.03～0.28） | 0.13 | 0.22、0.16、0.13、0.12 |
| | midtone | 0.31（0.22～0.44） | 0.42 | 0.34、0.37、0.32、0.24 |
| NLP | temp / midtone | | 0.66 / 0.48 | （4 组，每组 1～5 帧） |

新胶卷的 temp 和 tint 主要是逐帧变化；ev 和 midtone 有一部分卷级成分，对应翻拍曝光的逐卷差异。实验 B 按卷留出时，模型需要从画面统计里推断出曝光水平，而不能靠记住某一卷。

## 6. 异常

- **片基估计失败**：新胶卷 2/132 帧（A104、A198），自动片基找不到可用的候选区域。按设计不另外补救，这两帧不进入标签。
- **片基警告与误差无关**：带警告和不带警告的帧，P4 平均 ΔE 中位数分别是：新胶卷 4.56 / 4.28，店家 4.47 / 4.46，BlueNeg 7.67 / 7.85，NLP 7.66 / 4.82（带警告的只有 2 帧）。这和 S3-5 一致：警告标识不出受影响的帧。
- **低于黑点超过 5%**：新胶卷 37 帧（`dsc8242` 17 帧、`dsc6161` 16 帧、Gold 200 3 帧、`dsc6233` 1 帧），店家 2 帧。这些帧在**固定观感下同样低于黑点**，所以问题来自 P 乘以固定的 contrast 2.0，不是标签造成的。
- **新增高光裁切超过 2%**：2 帧（新胶卷 A027，BlueNeg `19970620C-10-st-michel`）。

## 7. 对后续实验的含义（未改动设计）

- 实验 A 和 B 都按原设计进入 M0～M2，不扩大范围。
- 在 `dsc6161` 卷和一部分低对比、低饱和的帧上，P4 的上限本身就有明显误差，评估模型时要单独看这些帧，这部分不能归咎于模型。
- 如果以后要提高表达能力，可以考虑把 contrast、sat 也放开（例如 P6 作为一个消融变体），或者改进片基估计。这些都属于以后另起版本的事，这一轮不做。
