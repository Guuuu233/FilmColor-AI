# S3：M3 探索性实验（冻结的 DINOv2-Small 特征 + Ridge）

日期 2026-10-17。**这是探索性结果**：实验 A 的第 1 级已经没有通过（`BASELINES_REPORT.md`），按固定顺序检验的规则，M3 不开启任何正式检验，也不改变已有的统计结论。M4（小 CNN）暂缓。冻结的两卷没有读取。

运行：`scripts/s3_baselines.py`（加入 M3）→ `m3/results.json`、`m3.log`（250 秒，主进程峰值 0.45 GiB）。重新跑出的 M0～M2 逐帧记录和分级统计，与已提交的 `baselines/results.json` 完全相同。

## 结论

1. **M3 没有改善实验 A**（BlueNeg 按卷留出，训练集 (a)，P4）：
   - 相对 M2 变差 +0.62（95% 置信区间 [+0.30, +0.99]，只有 13% 的卷改善）；
   - 相对 M1 是 +0.12（置信区间 [−0.09, +0.33]）；
   - 相对 M0 按折固定值是 −0.20（置信区间 [−1.00, +0.62]）。
2. **M2 在 BlueNeg 上的空间信息增益，M3 大多复现不了。** M2 比 M1 改善最多的那些帧，M3 大都回到 M1 的水平，例如 `199910-08-korea` 夜景：M1 23.01、M2 15.08、M3 21.24。两者相对 M1 的变化相关系数是 0.62，但 M3 只在 10 帧上胜过 M1，M2 是 18 帧。
3. **M3 没有缓解实验 B 的卷级系统偏差：**
   - Gold 200：M3 的 midtone 偏差是 +1.94 个尺度单位（M1 是 +1.95），误差 13.17，仍然比固定观感的 8.57 差；
   - `dsc6161`：误差 13.80，midtone 偏差 −2.08（M1 是 −1.72）；
   - 四个参数的逐卷偏差，M3 和 M1 基本相同。
4. **只在一卷上明显有效**：`dsc6233` 上 M3 是所有方法里最好的（6.41，M1 是 7.34，预测损失从 3.27 降到 2.00），但在 `dsc8242` 上比 M1 差（+0.57）。
5. **解读（推断，未验证）**：冻结的通用视觉特征加上 Ridge，没能从单张图里推断出各卷的影调和色彩水平。这些卷级因素（片种、翻拍曝光、调色师对这一卷的整体处理）可能不在单张图像的内容里，或者用这个规模的数据和这种特征提取不出来。这支持另行研究“卷级校准 + 场景自适应”的方向，但这个结论不是由正式检验得出的。

## 1. 实现（按设计第 3、4.1 节，没有新增特征或超参数）

- **权重**：`facebook/dinov2-small`，版本 `ed25f3a31f01632728cabb09d1542f84ab7b0056`。
  - `model.safetensors`：88 249 960 字节，sha256 `ae1e99fc…14be1`，与设计登记的值一致；
  - `config.json`：sha256 `1809f83e…8628d`；
  - `preprocessor_config.json`：sha256 `14e780d8…f828`。

  下载脚本 `scripts/s3_fetch_dino.py` 只取这三个文件，不用 torch.hub，不下载 pickle 格式的权重。权重放在外接盘的 `$FILMCOLOR_DATA_ROOT/models/`，以离线方式加载，只读 safetensors。
- **依赖**：新增可选的 `ml` 依赖组，torch 2.14.1（BSD-3）、transformers 5.20.1（Apache-2.0），确切版本锁在 `uv.lock` 里，引擎的核心依赖不变。
- **输入**（`filmcolor.learn.dino_input`）：
  - X8 按面积平均降采样到长边 224；
  - 按引擎默认参数渲染成 sRGB；
  - 短边用中性灰 0.5 补到 224×224，不裁画面；
  - 按 preprocessor 配置的均值和方差归一化。

  官方预处理默认会“短边缩到 256 再中心裁剪 224”，这里按设计没有裁剪，只取了归一化参数。
- **特征**（`scripts/s3_dino_features.py`）：最后一层的 CLS 向量（384 维）加 patch 平均（384 维），共 768 维。CPU 推理，eval 模式，不求梯度，不微调。189 帧共 57 秒。特征缓存记录了来源哈希。
- **M3**：在每个外层折内，只用训练帧做 PCA，取 16 维（所有折的训练帧都不少于 25 张），再拼上 F-glob 做 Ridge 回归。正则系数的候选值和内层留一卷选择方式都与 M1、M2 相同。PCA 是在外层折的全部训练帧上拟合一次的，在内层选正则系数时保持不变。内层被留出的帧参与了 PCA，但 PCA 不用标签，这只影响正则系数的选择，不影响外层评估。

## 4. 对下一步的含义

- 在这些数据上，没有证据显示 M4（从零训练的小 CNN）会有帮助：冻结的通用视觉特征都没有识别出卷级水平，只靠 4 卷新数据训练的 5 万参数网络，预期更难做到。建议 M4 继续暂缓。
- 系统偏差主要在卷级，尤其是 midtone 和 temp，这一点在 M1、M2、M3 中都一致。如果要研究“卷级校准 + 场景自适应”，需要先定义卷级输入（同卷其他帧的统计、片种、翻拍批次），并另起实验版本，重新做预先登记。这超出了本轮设计的范围。
- 所有结果都是开发集上的探索性结果，冻结测试集没有打开。
