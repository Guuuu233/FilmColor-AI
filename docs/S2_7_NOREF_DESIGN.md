# S2-7 无参考自动优化器：设计草案（待确认）

目标：只根据负片本身（以及同一卷的其他画格），自动给出 7 个逐张参数；不看任何正片参考。
这是要被后续 AI 超过的传统算法基线。

## 1. 信息边界

| 可以用 | 不可以用 |
|---|---|
| 本帧 RAW → 片基、反转后的场景线性正片 P、sidecar 诊断 | NLP 或店家正片（求解时） |
| 同一卷其他画格的统计（整卷片基、整卷亮度 / 色度分布） | fit_config_v1 的参数标签（求解时） |
| 在开发数据上**调定**的少量超参数（目标亮度、饱和度默认值等） | 按单张参考图逐张调参 |

开发数据（NLP 12 张 + shop_r01）可以用来调这些全局超参数，并且要在报告里写明是在哪些数据上调的。
参考图只用于评估。正式结论要等新胶卷保留集。

## 2. 结构：分组估计，不做一个大黑箱目标

每组参数各用一个可解释的统计量来定，最后只用一个小的联合步骤处理影调和高光之间的冲突：

| 参数 | 依据（无参考） | 防止误判 |
|---|---|---|
| ev、midtone（亮度） | 画面亮度的稳健分位数（不是均值），映射到在开发数据上调定的目标区间 | 逆光 / 低调场景：用分位数分布而不是固定均值；受高光预算约束（见下） |
| temp、tint（白平衡） | 低饱和像素的平均色度（只用“接近中性”的像素，不是全图灰世界），向整卷估计和 0 收缩 | 夕阳、夜景等主色调场景：近中性像素少或色度分布集中时降低置信度、加大收缩；幅度设上限 |
| contrast、shoulder | 画面亮度的有效动态范围（如 p1～p99）映射到目标范围；shoulder 由高光预算决定 | 已经是高反差的场景不再加反差 |
| sat | 开发数据上调定的全局默认值（两套参考的拟合中位数都约 1.2），可按画面色度做小幅调整 | 已经很饱和的画面不再加 |

## 3. 无参考的高光保护（不依赖参考图）

- **第一层：新增裁切预算**。“原图在这里有层次、渲染后被推过白点”的面积不超过预算（例如 0.5%）。用的是 `clip_area`，
  但豁免条件改成看输入：输入本身已经无层次（达到传感器饱和或密度接近白点上限）的像素不计。
- **第二层：高光压缩比**。比较输出高光区的局部层次和**输入 P 在同一区域的局部层次**（对数域），比值过低说明被压平。
  这不需要参考图，和 S2-6c 的诊断思路一致，只是把对照对象从参考图换成了输入本身。
- 两层都只在开发数据上调定阈值。

## 4. 输入质量检测（3858 这类画格）

- 低信息量指标：画面中密度接近片基（未曝光）的比例、有效动态范围、近黑或近白比例、整卷相对位置（卷首卷尾）。
- 超过阈值时：输出**低置信度**并标记“需要人工检查”，参数保守处理（接近默认值或整卷中位数），**不强行套亮度分布**。
- 结果写进 sidecar：每组参数的置信度和触发了哪些保护。

## 5. 评估

- 对照组：默认参数；“一套固定校正全卷共用”（留一法）；fit_config_v1 标签（看过参考图的上限）。
- 指标：相对 NLP / 店家的 ΔE（中位数、p90）、新增裁切、高光层次比值、参数离 v1 标签的距离（尺度单位）；
  按开发数据和异常帧分开统计。
- 所有图逐张出预览，失败的看图归类（亮度、白平衡、反差、饱和度、输入质量），作为以后 AI 要学什么的依据。
- 判定：明显优于默认参数和“固定校正”才算有价值；距离上限多远，说明还剩多少需要学习的部分。

## 6. 不做

不训练神经网络、不做 GUI、不做光谱模拟；色彩矩阵仍为单位矩阵；不改基础引擎的默认输出。
