# FilmColor AI 项目方案 V0.2

**制定日期：2026-10-13｜状态：执行中（Sprint 1）**
**前序版本：** `FilmColor_AI_项目方案_v0.1.md`（ChatGPT 起草），经 Claude 审查与 ChatGPT 复核共三轮讨论后形成本版。
**本文件是所有编码 Agent 的统一项目依据。** 与本文件冲突的旧方案内容以本文件为准。

---

## 一、项目定位

面向胶片摄影爱好者的**独立桌面**负片转换与校色软件（优先 macOS / Apple Silicon，本地离线运行）。

### 1.1 差异化（V0.2 修订）

- NLP v3.0（2023-07-28）已提供 Roll Analysis（Pro Lab / Basic Lab / Darkroom Paper），基于统计分析，未使用 AI。**“整卷一致性”不再作为差异化卖点。**
- NLP 仍是 Lightroom 插件；“独立软件、不依赖 Lightroom”是真实但非核心的差异。
- 核心目标改为可测量的：**在不增加操作负担的前提下，提高自动转换的首次成功率，减少困难照片的人工调整，同时保持整卷场景关系。**
- 接受一种可能结局：主要收益来自校准良好的确定性引擎而非神经网络。若如此，产品照样成立，不强行加入 AI。

### 1.2 项目性质

先研究、后产品化：先证明能更可靠地校色 → 再做成软件 → 最后验证付费意愿。三者分别验证。

## 二、技术路线

```text
RAW（ARW/DNG 等）/ 16-bit TIFF
  → RAW 解码与线性化（黑/白电平、有效像素）
  → 片基 / 色罩估计（自动或手动指定区域；可整卷共享）
  → 密度空间反转 + 基本色调映射            ← 确定性引擎（Sprint 1）
  → 校色参数预测（参数回归，θ 与 UI 滑块同一套）← AI，第 5～8 周起
  → 可微渲染 / 高精度渲染
  → 16-bit TIFF / JPEG
```

原则：

1. **确定性反转引擎先于 AI**，独立模块、独立数值测试，与 AI 参数预测不混合。
2. 每一步明确**信号定义与色彩空间**（传感器线性 RGB / 密度 / 输出空间）；处理位置（如是否在相机矩阵之前）以校准与对照实验决定，不预设定律。
3. **AI 第一版 = 参数回归**：网络预测具有摄影/物理意义的参数 θ（通道增益、密度黑白点、通道 gamma/曲线、颜色矩阵等），渲染器确定性执行。训练用输出图像误差 + 参数正则化 + 已知校准约束联合约束（参数不唯一）。
4. **3D LUT** 保留为候选，仅当参数回归表达力不足时再引入。
5. **VLM 不进入第一版**；需要场景/光源识别时先用小分类器。
6. **必须保留非神经网络的参数优化器作为基线**；若普通优化即可达到同等效果，不引入 AI。
7. 不使用生成式模型重绘像素。

### 2.1 物理仿真的定位

- 光谱/胶片正向仿真为**辅助**：扩充数据、覆盖极端条件、提升对扫描条件变化的鲁棒性。
- 真实负片负责：确定研发目标、校准仿真器、最终评估。仿真成绩不得冒充真实胶片效果。
- 完整光谱仿真器在三项核心任务有结果前**不投入**。

### 2.2 算力

本地 Mac（M3 Pro，18 GiB）优先；Google Colab 作为加速器，不进入关键路径。训练前用固定任务对比 CPU / MPS / Colab 的耗时、显存与数值一致性（含 MPS 上 5D `grid_sample` 反向传播）。

## 三、数据策略

| 数据 | 来源 | 用途 | 状态 |
|---|---|---|---|
| 公开负片 RAW | NLP 官方样本包、NLP 论坛配对案例 | 引擎开发、对照、多设备独立测试 | Sprint 1 下载审核 |
| NLP 输出 | 用户自有 NLP 授权 | 对照基线（问题 A/B，见第五节）；可作部分标签 | EULA 未明确训练用途，商用前须确认 |
| 人工可控色偏 | 在公开 RAW 上构造 | 第 5～8 周验证学习方法（不代表胶片校色能力） | 待做 |
| 自拍新胶片 + 色卡 + A7R III 数码参考 + 冲扫店扫描 | 2027 年 1 月后 | 训练、仿真器校准、“场景还原”目标的 ΔE 评估 | 采集规范第 9～12 周写好 |
| 已有旧胶片 | 2027 年 1 月后 | 独立测试、偏好学习、真实负片域适应 | 待取回 |

要点：

- **色卡官方标定值才是颜色真值**；数码 RAW 与胶片翻拍都需经同一色卡特性化后才能比较。数码 RAW 本身不等于场景真值。
- 区分两类目标并分别评估：**场景还原**（色卡 ΔE00 等客观指标）与**胶片呈现**（冲扫参考 + 主观盲测）。
- 自有数据来自单一设备链，存在分布偏差；**独立评估必须包含其他摄影师、批次和扫描设备的数据。**
- 数据集按胶卷、扫描批次、设备管理；划分训练/验证/测试时同一卷不跨集合。
- FiveK 等研究用途数据集及其衍生预训练权重**不得进入商业产品**。

## 五、评估口径

- 对照组是 **NLP 默认输出**，不是自建传统基线。
- **问题 A（自动化）**：AI 能否以更少人工操作达到 NLP 人工精调的效果。
- **问题 B（竞争力）**：AI 在独立参考与盲测中能否优于 NLP 默认输出。
- 核心指标：自动转换首次成功率、需要人工调整的张数与参数量；同时比较调整后质量，防止以质量换操作次数。
- 盲测需足够多的独立场景和评价者，并报告不确定性。

- 维护依赖许可证清单与数据来源清单（`data/manifests/`）。

## 七、Sprint 1：确定性负片反转引擎（第 1～2 周）

**目标：** 独立、可测试的 RAW 彩色负片转换原型，作为后续 AI 校色的处理基线。

**范围外：** GUI、AI 训练、光谱仿真、额外功能。

工作单元（逐个独立验收，不一次性开发整个模块）：

| # | 单元 | 验收证据 |
|---|---|---|
| S1-1 | 项目目录、Python 环境、README、数据规范、实验记录模板 | 目录与文档存在；环境可复现安装 |
| S1-2 | 下载 NLP 官方 RAW 样本，核对格式、数量、完整性、设备、许可 | `data/manifests/` 样本清单 + 校验和 |
| S1-3 | RAW 解码：黑电平、白电平、线性化、有效像素区域 | 数值测试（已知元数据对照、饱和/裁切检查） |
| S1-4 | 片基估计：自动 + **手动指定区域**；缺少胶片边缘时的处理 | 稳定性测试（区域扰动下估计值变化有界） |
| S1-5 | 密度计算、反转、基本色调映射；每步数学定义与色彩空间写入文档 | 单元测试 + 有效动态范围检查（裁切比例） |
| S1-6 | 16-bit TIFF 导出，含必要的颜色管理信息（ICC） | 读回校验位深与 ICC |
| S1-7 | 处理参数与诊断信息完整输出（sidecar JSON），结果可复现 | 同输入同版本两次运行逐像素一致 |
| S1-8 | 异常输入测试与基础图像质量检查 | 测试通过 |
| S1-9 | 与 NLP 默认转换的对照机制与差异分析 | 首份对照报告（`experiments/`） |

**验收：** 稳定处理首批真实负片 RAW，输出可观察、可解释、可复现，自动化测试通过；色彩质量须与 NLP 对照分析，不以“成功导出文件”作为验收依据。

**第一周交付物：** 真实 RAW 样本清单、可运行的最小反转程序、数值测试、第一份 NLP 对照报告。

## 八、工程原则

- 编码 Agent 报告“完成”不等于验收；每个单元需要测试、运行记录、输出样本与验收结果。
- 核心色彩处理写成纯函数并配测试，便于未来移植（Swift/Metal 等）。
- 不在 AI 效果验证前采购 GPU、训练服务器、专业扫描设备或光谱仪。
