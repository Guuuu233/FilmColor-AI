# S3 机器学习可行性实验：设计（待审查，未实施）

日期 2026-10-15。依据：S3-3（`experiments/s3_blueneg/REPORT.md`）、S3-5（`BASE_REPORT.md`），以及 2026-10-15 用户和 GPT 的审查意见。**本文件只做设计**：不生成标签、不训练、不改反转和渲染引擎。审查通过后才开始实施。

## 0. 要回答的问题

**图像内容能不能帮助模型，在没参与训练的胶卷上，比固定观感和全局统计更可靠地选出校色参数？**

这一轮只做“场景感知的校色参数回归”，要解决的是预测出接近某种参考外观的参数，而不是还原场景的真实光照。S3-5 已经表明，在没有片边的扫描上，片基估计误差和白平衡在结果上混在一起，所以模型预测的色彩平衡里包含对片基误差的补偿。所有结论都只是开发集上的可行性证据，不代表商业级的泛化能力。

## 2. 输出参数和标签

### 2.1 输出空间

| 变体 | 预测 | 固定（取 θ_fixed） |
|---|---|---|
| **P4（主变体）** | ev、midtone、temp、tint | contrast、sat、shoulder |
| P3（消融） | midtone、temp、tint | ev、contrast、sat、shoulder |

依据：S2-7 的逐组上限分析和 S3-5 的归因都表明，主要困难在亮度和色彩平衡。P3 用来检验 ev 和 midtone 的高度相关（0.81～0.98）是否影响学习的稳定性。

### 2.2 θ_fixed 的来源（防泄漏）

- **BlueNeg 按卷留出（主实验）**：θ_fixed 直接取 `global_look_v1` 中的 contrast、sat、shoulder（P3 再加上 ev）。`global_look_v1` 只用 NLP 和店家数据拟合（见它的 `fit.train` 字段），没见过 BlueNeg，所以对 BlueNeg 的任何一折都不构成泄漏。整个主实验只需要一套标签。
- **留一数据域（辅助实验）**：测试域是 NLP 或店家时，`global_look_v1` 用到过这两个域，必须在这一折里重新拟合固定观感。做法和 `scripts/noref_global.py` 相同（mode 7、λ=0、`fit_config_v1` 的高光约束、每帧 3000 像素），只用训练的两个域，再从结果里取 θ_fixed，并据此重新生成这一折的标签。测试域是 BlueNeg 时，直接用 `global_look_v1`。

### 2.3 受约束标签 `fit_config_s3_p4` / `fit_config_s3_p3`

不能直接从 7 参数的 `fit_config_v1` 标签里抽 4 个值，因为 7 个参数之间会互相补偿。标签按下式定义：

  θ\*_free = argmin  L_ref( R(P; θ_free, θ_fixed) ) + λ Σ ((θ_i − θ_i,default) / s_i)²

除了自由参数和固定值不同，其余都沿用 `fit_config_v1`：λ=0.05，尺度 `SCALES`，深度权重 30，面积权重 10，起点数、随机种子、采样像素数、迭代上限都相同，正则项的中心仍是引擎默认值。拟合网格是 1/8 分辨率（BlueNeg 用 S3-3 的配准；NLP 和店家用已有的 P8 / R8 缓存）。

代码改动只有一处：给 `fit.fit_reference` 加一个 `fixed: dict | None = None` 参数，让不在自由列表里的参数可以取指定值（目前一律取默认值）。默认为 `None` 时行为不变；`FIT_CONFIG_V1` 和它的核对入口不改；两个新配置照 v1 的方式冻结并做核对。

标签的多起点稳定性、碰到边界的比例、新增裁切比例，都要和 v1 一样记录并报告。

## 3. 输入和特征

所有输入都只来自这一帧的反转正片 P（`invert_negative` 的输出乘以曝光），不读参考图，也不读任何标签。

| 编号 | 输入 | 维度 |
|---|---|---|
| F-glob | 全局统计：log 亮度在 1/5/25/50/75/95/99% 分位的值；log(R/G)、log(B/G) 的均值、中位数，以及近中性像素的中位数；各通道在 99.9% 分位处的值；饱和度的中位数 | 约 20 |
| F-grid | 3×3 网格，每格的 log 亮度均值和 log(R/G)、log(B/G) 均值（便宜的空间基线） | 27 |
| F-dino | 冻结的 DINOv2-Small 特征：CLS 向量 + patch 平均，共 768 维，在训练折内用 PCA 降维。输入是默认参数渲染出的 sRGB 图，224×224 | ≤ 16（PCA） |
| X-cnn | 小 CNN 的输入：log₂ P，降采样到 96×96 | — |

另外记录片基估计是否带警告、输入来源（相机 RAW 或扫描仪）。第一版**不作为特征**（避免模型把设备背下来），只用于分组分析。

## 4. 方法（第一轮只比这几种）

| 编号 | 方法 | 可训练的部分 |
|---|---|---|
| M0 | 固定观感：`global_look_v1`（BlueNeg 各折不泄漏）；另报一个**按折重新估计的固定值**，即训练折标签每个参数的中位数 | 0 / 4 个数 |
| M1 | F-glob 加 Ridge 回归 | 约 80 |
| M2 | F-grid（加 F-glob）加 Ridge 回归 | 约 200 |
| M3 | F-dino（加 F-glob）加 Ridge 回归 | 约 150 |
| M4 | 小 CNN：4 层 3×3 卷积（16/32/48/64 通道，步长 2）、全局平均池化，再接全连接输出 4 个值 | 约 4.7 万 |

- Ridge 用 numpy 的闭式解实现，**不新增 scikit-learn**。特征标准化、PCA、正则系数都只在训练折内拟合；正则系数用训练折内部的“留一卷”来选，嵌套在外层折里面。
- CNN：先不做参数规模搜索。用 Adam，带权重衰减，**训练轮数事先定死**（不对测试卷做早停），跑 5 个随机种子并报告平均值。数据增强只用几何变换（翻转、90° 旋转、裁剪），这些变换不会改变标签。“与标签一致的光度增强”（输入整体乘以 2^a 和白平衡增益，标签相应平移）留到第二轮做消融。
- 损失函数：按尺度加权的参数均方误差 Σ((θ̂_i − θ\*_i)/s_i)²，尺度用 `SCALES`（ev 1.0、temp 0.25、tint 0.25、midtone 0.05）。可微的图像损失留到第二轮，前提是参数误差和图像误差明显对不上。
- 依赖：M3、M4 需要 PyTorch（BSD-3）；M3 还需要 `transformers`（Apache-2.0）。这些都放进单独的 `ml` 依赖组，不进入引擎核心依赖。

### 4.1 DINOv2-Small 的登记信息（2026-10-15 已核实）

- 权重：Hugging Face `facebook/dinov2-small`，版本 `ed25f3a31f01632728cabb09d1542f84ab7b0056`（最后修改 2023-09-06），许可证标签 `apache-2.0`；GitHub `facebookresearch/dinov2` 的 LICENSE 是 Apache License。
- 加载方式：只加载 `model.safetensors`，并固定上面的版本号，下载后核对 sha256。**不用 `torch.hub`**（会下载并执行远程代码），也**不用 `pytorch_model.bin`**（pickle 格式）。
- 局限：ViT-S/14，约 2100 万参数，只做冻结的特征提取，不打算放进桌面产品。训练数据 LVD-142M 是网上收集的图片，权重的 Apache 授权不等于训练数据有授权，正式商用前要做法律审查。

## 5. 验证

### 5.1 主实验：BlueNeg 留一卷（23 折）

每一折留出一整卷（1～2 张）。全部预测拼起来以后，计算各项指标。

- 训练集构成：**(a) 只用 BlueNeg 的其余卷（主实验）**；(b) 再加上 NLP 和店家的全部 32 张（消融，检验其他数据域的数据是有帮助还是有干扰）。
- 不确定性：以卷为单位做自助抽样（10000 次），给出“方法减基线”的逐帧 ΔE 差值的 95% 置信区间。
- 同时报告：逐卷改善率、逐帧误差分布、最差的 5 张及其图像。

### 5.2 辅助实验：留一数据域（3 折）

按第 2.2 节逐折重新拟合 θ_fixed 和标签。三个数据域分别报告结果，不报总体平均。结论只能说“数据域整体变化下的迁移能力”（包括设备、胶片、参考风格三方面），不能说成是设备泛化。

### 5.3 防泄漏清单（实施时逐项核对，写进报告）

1. 测试卷的标签和参考图，只在冻结模型之后用来计算指标。
2. θ_fixed、M0 的按折固定值、特征标准化、PCA、Ridge 的正则系数、CNN 的训练轮数，都只用训练折的数据确定，或者事先定死。
3. 不把同一卷拆到训练和测试两边。店家数据只有 1 卷，不做内部交叉验证。
4. 模型选择和超参数不看任何外层测试折的结果。如果在看过结果之后改了设计，就要另起一个版本号，并在报告里写明。

## 6. 指标和事先定好的成功标准

逐帧指标都在 1/8 分辨率的配准网格上计算：

- 渲染后相对参考的 ΔE2000 中位数（主指标）；
- 按尺度归一的参数误差；
- 平均 ΔL\*、Δa\*、Δb\*；
- 新增高光裁切面积（用 `fit.clip_area`，以参考图已裁切的区域为豁免）；
- 异常输出：画质检查为 fail，或新增裁切超过 2%。

另外报告两个参照：标签本身的渲染误差（P4 或 P3 的上限），以及 7 参数 v1 的上限。

**成功标准**（看结果之前定下，不再修改）：

| 结论 | 条件（BlueNeg 留一卷；事先指定训练集构成 **(a) 为主**，因为它参考风格一致，这正是主实验的意义所在；(b) 作为消融单独报告，不用来下这三项结论） |
|---|---|
| 学习方法有价值 | 某个方法相对 **M0 按折固定值**的逐帧 ΔE 差值，95% 置信区间的上界小于 0，**并且**改善的卷不少于 60%，**并且**新增裁切超过 2% 的帧数不多于 M0 |
| 空间信息有增量价值 | M2、M3 或 M4 相对 M1 满足同样的置信区间条件 |
| 神经网络有必要 | M3 或 M4 相对 M2 满足同样的置信区间条件；否则结论是“现有数据下，便宜的空间统计就够了” |

任何一项不满足，都如实报告为“没有证据”，并给出失败样本分析，不另找指标来补救。

## 7. 计算量（估算）

- 标签：主实验用一套标签，59 张 × P4、P3 两种，共 118 次拟合；留一数据域中测试域为 NLP 和店家的 2 折，各自用新的 θ_fixed 给全部 59 张重新生成标签（测试域的标签只用来算上限），共 2 × 59 × 2 = 236 次。每次拟合约 10～30 秒，8 进程并行，预计 1～2 小时。
- 特征和 Ridge：分钟级。DINOv2 在 59 张图上前向推理：在 M3 Pro 上是分钟级。
- CNN：23 折 × 5 个种子，96×96 的输入，约 4.7 万参数，在 CPU 或 MPS 上预计 1 小时以内。
- 内存：单进程不超过 6 GiB，按 S3-2 的口径实测并记录。
- 缓存：P8、R8、特征和模型文件暂时放在 `experiments/s3_ml/cache/`，不进 git。以后数据根目录可配置（`FILMCOLOR_DATA_ROOT`）之后，再迁到外接盘；迁移规则见存储方案（先复制、核对 SHA256、再删除，外接盘断开时报错，不悄悄在内置硬盘上新建目录）。
