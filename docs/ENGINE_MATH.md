# 确定性反转引擎：信号定义与数学

本文件描述 Sprint 1 引擎每一步的输入、输出、信号含义和色彩空间。代码：`src/filmcolor/raw.py`、`base.py`、`invert.py`。

## 1. RAW 线性化（S1-3，`raw.py`）

| 符号 | 含义 | 色彩空间 / 单位 |
|---|---|---|
| `cfa` | 可见区域的原始传感器值 | DN，单平面 CFA |
| `pattern` | CFA 排列，0=R 1=G 2=B（Bayer 第二个绿合并为 1） | Bayer n=2，X-Trans n=6 |
| `black` | 每个 CFA 位置的黑电平 | DN |
| `linear` | `(cfa - black) / (white - black)` | 相机原生线性 RGB 采样，0=黑电平，1=白电平；无白平衡、无色彩矩阵；读出噪声造成的负值保留 |

两条路径：

- **分析路径**：按 CFA 颜色分别统计（`channel_stats`、`superpixel`），不同颜色的采样从不混合平均。用于片基估计、曝光统计、诊断。
- **渲染路径**：`rawpy_io.demosaic_linear`，LibRaw 全分辨率反马赛克，关闭白平衡、色彩矩阵、自动亮度、`adjust_maximum`；与 `linear` 同一标尺，但低于黑电平的值被截为 0。

两条路径的通道均值差 ≤ 0.8%（12 张全测，`experiments/s1_diag/dual_path.json`）。原因见 `experiments/s1_diag/b_bias_notes.md`：同色不同 CFA 位置的感光不完全相同，不同算法的插值权重不同。**因此片基与画面必须在同一信号上测量**（第 3 节）。

## 2. 片基估计（S1-4，`base.py`）

在分析路径上自动（饱和块排除 → 均匀性筛选 → 最亮候选 → 色度一致性）或手动（多区域）估计，输出采样区域、各通道统计和诊断。

## 3. 密度与反转（S1-5，`invert.py`）

| 步骤 | 定义 | 含义 |
|---|---|---|
| 渲染信号 | `T` (H, W, 3) | 渲染路径线性相机 RGB |
| 片基 | `b = median(T over base regions)` | `base_from_regions`：用第 2 节选出的区域，在**渲染信号**上取中位数 |
| 透射率 | `t = T / b` | 相对片基的透射率，片基处为 1 |
| 密度 | `D = -log10(max(t, 1e-6))` | 片基以上的密度；片基处 0，曝光越多越大；比片基更透的区域为负 |
| 归一化 | `s = (D - D_lo) / (D_hi - D_lo)` | 每通道独立；黑点 `D_lo` 默认 0（片基 = 零曝光），白点 `D_hi` 默认取画面区域内 99.9% 分位 |
| 正片线性值 | `P = (10^(R(s-1)) - 10^-R) / (1 - 10^-R)`，`R = (D_hi,G - D_lo,G) / γ` | 黑点→0，白点→1；`γ` 为胶片 gamma（默认 0.6），决定场景对数范围 R |
| 显示编码 | `O = sRGB_OETF(clip(exposure · P, 0, 1))` | 仅用于观看 |

**模型依据。** 在特性曲线直线段，负片密度 `D_c ≈ γ_c · log10(E / E0)`。对中性灰阶，各通道 `s_c = log(E/E0) / log(E_max/E0)` 与 `γ_c` 无关，因此每通道独立归一化可以消除各层 gamma 差异和色罩，得到中性输出；当 `γ` 等于绿层 gamma 时，`P` 精确还原 `(E - E0) / (E_max - E0)`（`tests/test_invert.py` 验证）。

**假设（可被参数覆盖）：**

1. 片基 = 零曝光，故默认黑点为 0。真实场景的深暗部密度接近片基，会被压到 0（见已知问题）。
2. 画面最亮的高光是中性色，故三通道白点分别取分位数。画面无中性高光时会偏色。
3. 画面区域默认是**居中、各边 50%** 的矩形（`central_region`）：翻拍常含片夹遮罩（极高密度）与片边/背光（低密度），都不能参与白点统计。可手动指定画面区域。`full_image_above_white` 报告全图高于白点的像素比例，比例大说明存在不透光区域或画面区域外有高光。
4. 无串扰模型：真实染料的通道串扰未建模，留给后续校准。

**色彩空间。** `P` 和 `O` 都是**未经色度校准的相机 RGB**（翻拍相机 × 胶片染料），未套用任何色彩矩阵。`O` 只套了 sRGB 传递函数便于观看，原色并不是 sRGB。S1-6 导出时必须如实标注。

## 4. 诊断（`range_report`）

每通道：`clip_high`（画面区域高于输出白的比例）、`below_black`（低于黑点）、`brighter_than_base`（比片基更透）、密度 0.1% / 99.9% 分位；以及 `full_image_above_white`。全部参数由 `InversionParams.to_dict()` 输出，可写入 sidecar。
