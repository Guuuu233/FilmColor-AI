**Changes made.** Each RAW was converted from negative to positive with FilmColor v2.0 (default engine, the preset
named under each tile, automatic crop) with no manual adjustments, then cropped to the exposed frame, resized and
arranged with labels. The "Original negative" tiles are the same RAW rendered without inversion.

**Licence of these images.** `showcase_before_after.jpg`, `showcase_presets.jpg` and `ui_preview.png` are
adaptations of the works above and are released under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); when reusing them, credit the
photographers as listed above. This licence covers only these image files, not the FilmColor source code.

Some of these public frames were also among the unpaired negatives used to train FilmColor v2.0, so they show
typical output rather than accuracy on unseen frames; see the blind benchmark in the README for the latter.
