# Sprint 2 设计：参数化校色引擎与两种优化器

状态：2026-10-14 用户批准（含 GPT 修正）；SciPy 依赖获批，在优化器单元引入。

## 目标

1. 在 Sprint 1 的确定性反转之后，加一组**可解释、可保存、可手动修改**的校色参数。它们就是将来用户界面上的滑块，也是 AI 要预测的 θ。
2. 两种优化器严格分开：
   - **参考图拟合器**（研究工具）：已知参考图（NLP），找最接近它的参数，用来检验参数空间的表达能力。不进产品。
   - **无参考自动优化器**（产品基线）：只看负片本身的统计量来定参数。AI 将来必须超过它。
3. 暂不训练 AI，不做 GUI、VLM、光谱模拟。

## 处理顺序与参数

在现有链路 `RAW → 线性化 → 片基 → 密度 → 各通道黑白点归一化 → 正片线性值 P` 之后，按固定顺序（`src/filmcolor/render.py`）：

| # | 环节 | 参数（默认值） | 范围/约束 | 信号 |
|---|---|---|---|---|
| 0 | 密度反转（已有） | 各通道黑点 `d_lo`、白点 `d_hi`（自动）；胶片 gamma 0.6 | `d_hi > d_lo` | 密度 → 场景线性 P |
| 1 | 曝光 | `ev`（0） | [−3, +3] 档 | 场景线性：`x · 2^ev` |
| 2 | 白平衡 | `temp`、`tint`（0, 0） | [−1, +1] | 场景线性：通道增益，见下 |
| 3 | 色彩矩阵 | 3×3 `M`（单位阵） | 每行和 = 1；对角 [0.5, 2]、非对角 [−0.8, 0.8]；条件数 ≤ 10 | 场景线性 |
| 4 | 饱和度 | `sat`（1） | [0, 2] | 场景线性：`Y + sat·(x − Y)` |
| — | 负值处理 | — | 第 3、4 步后 `< 0` 的值截为 0，比例写入诊断 | 场景线性 |
| 5a | 高光压缩 | `shoulder`（0） | [0, 1] | 场景线性 → 显示线性 [0, 1] |
| 5b | 中间调 | `midtone`（0.18） | [0.05, 0.5] | 显示线性：绕白点的幂函数 |
| 5c | 反差 | `contrast`（1） | [0.5, 2] | sRGB 编码域：S 曲线 |
| 6 | 输出编码 | sRGB / 线性 | — | 5c 的结果已是 sRGB 编码；线性输出 = 反 OETF |

**说明与定义：**

- **色温、色调是相对冷暖/品绿调节**，单位是 log2 增益，不对应开尔文值（RGB 未经色度校准）。`temp = t`：R 增益 `2^(t/2)`、B 增益 `2^(−t/2)`；`tint = u`（+ 偏品红）：G 增益 `2^(−2u/3)`、R/B 各 `2^(u/3)`。三个增益再整体归一，使中性色的亮度 `Y` 不变。
- **亮度权重 `Y`** 用 Rec.709 系数（0.2126, 0.7152, 0.0722），对应“按 sRGB 原色解读”的假设。
- **色彩矩阵属于“翻拍设备 + 光源 + 胶片”组合的校准配置**，不按胶卷型号共用。第一版默认单位阵，可从外部传入；校准流程以后再做。每行和为 1 只保证中性色保持中性，不足以保证变换合理，所以另加系数范围和条件数约束，矩阵与饱和度之后的负值截为 0 并记录比例。
- **胶片 gamma 0.6 是当前引擎的基准假设**，不是适用于所有胶片和显影条件的常数。
- **影调曲线（逐通道相同）**：
  - 5a 高光压缩：扩展 Reinhard，`v = u(1 + u/Lw²)/(1 + u)`，`Lw = 1 + 7·shoulder`，`v(Lw) = 1`；`shoulder = 0` 时为恒等，再截到 1。
  - 5b 中间调：`y = v^γ`，γ 使场景 18% 灰（曝光后）落到显示线性值 `midtone`；黑点 0、白点 1 不动。
  - 5c 反差：在 sRGB 编码值 `e` 上，以 `p = oetf(midtone)` 为支点做分段幂函数（`e ≤ p`：`p(e/p)^c`；`e > p`：`1 − (1−p)((1−e)/(1−p))^c`）；黑点、白点、支点都不动，支点处斜率 = `contrast`。
- **为什么这样定义（参数可辨识性）**：如果曝光是乘系数、反差和中间调都是幂函数，三者合起来只有“缩放 + 幂”两个自由度，会互相抵消，拟合与 AI 都无法分辨。现在三者形状不同：曝光 = 缩放，中间调 = 端点固定的幂，反差 = 端点和支点都固定的 S 曲线。测试用输出对 7 个参数的数值雅可比矩阵满秩来验证。
- **实测可辨识性（`tests/test_render.py`）**：7 个参数的雅可比矩阵满秩，但条件数比值只有约 0.03。原因是 `ev` 与 `midtone` 高度相关（列向量夹角余弦约 0.91，两者都提亮中间调，只在高光裁切和暗部才有区别）；其他参数之间没有明显重叠。去掉二者之一，比值升到约 0.31～0.35。
- **待确认（优化器单元前）**：7 个参数都保留给用户手动调整；**优化器与 AI 只预测 6 个，`ev` 固定为 0**，画面亮度由 `midtone` 控制。理由：自动白点已把高光定在 1，再调 `ev` 主要是把高光推向裁切；`midtone` 保持白点不动，作为自动亮度控制更稳。
- **诊断只统计画面区域**（片基、片夹区域的值接近 0 或极大，会主导统计）。实测 `_DSF8983`：默认参数下矩阵/饱和度后被截掉的负值占画面 0.05%，`sat = 1.5` 时 1.8%（高饱和颜色）。截断是最简单的色域处理，可能带来轻微色相偏移，以后需要时再换成色域映射。
- **观感注意**：`midtone` 保持黑白点不动、整体提亮中间，单独提高时暗部会发灰，需要配合 `contrast`（实测 `_DSF8983`，`experiments/s2_render/`，图片不进 git）。
- **全部默认值下输出与 Sprint 1 完全一致**（`srgb(clip(P))`）。Sprint 1 反转参数里的 `exposure` 保持 1，曝光统一由 `ev` 控制。

## 两种优化器

**逐张参数**（自动优化器和拟合器都调）：`ev, temp, tint, sat, contrast, midtone, shoulder`，共 7 个。
**共用参数**：矩阵 `M`，属于翻拍设备 + 光源 + 胶片的校准配置；第一版为单位阵，拟合器可在同一配置的一组图上拟合，自动优化器使用固定值。

- **参考图拟合器**：在与 S1-9 相同的对齐网格上，最小化相对参考图的 ΔE00（加参数正则），有界优化，初值固定，结果确定。
- 两种优化器可以都用 `scipy.optimize`，但**目标函数不同**：拟合器最小化与参考图的差异；自动优化器没有参考答案，只能用曝光统计、中性约束、颜色分布先验。先验必须谨慎，不能强制每张图中性白平衡（夕阳、夜景、室内灯光会被错误校正）。
- **无参考自动优化器**：用图像自身统计量定参数，例如按画面对数平均亮度定 `ev`，按高光与近中性区域定 `temp/tint`，按直方图展宽定 `contrast`，`sat` 用固定默认。它可能有少量超参数（比如目标中间调），**只能在训练划分上调，留一法评估**，不得用被评估图的参考结果。

## 评估协议

对同一批图报告：基础引擎（Sprint 1）、无参考自动优化器（留一法）、参考图拟合器（样本内上限）。指标沿用 S1-9（明确标注为“相对 NLP 的输出差异”），加 QC 检查。

**参考组**：

- `nlp_default`（已有，Roll Analysis 开）
- `nlp_noroll`（**待用户导出**：关闭 Roll Analysis，其他设置不变）
- 以后若能确定真实的胶卷分组，再加“按正确分组的 Roll Analysis”。现在 `roll_id` 只是翻拍日期，不是胶卷。
